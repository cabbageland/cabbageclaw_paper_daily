# Decision Titan: Test-Time Training for Long-Term Memory in Offline Reinforcement Learning

## Basic info

* Title: Decision Titan: Test-Time Training for Long-Term Memory in Offline Reinforcement Learning
* Authors: Jude Waide, Robert Lieck
* Year: 2026
* Venue / source: arXiv
* Link: https://arxiv.org/abs/2610.01513
* Date surfaced: 2026-10-04
* Why selected in one sentence: It tests whether Titans-style fast-weight memory can give Decision Transformers usable long-term memory in offline RL, then analyzes where that memory succeeds and fails.

## Quick verdict

Useful.

This is not as broad as the strongest world-model papers, but it is a good mechanism study. The value is in the controlled X-Maze setup and the gate/momentum analysis, not in claiming that the architecture solves long-horizon RL. The paper is refreshingly clear that TTT memory depends on recall cues, training over full trajectories, and fragile memory dynamics.

## One-paragraph overview

Decision Titan inserts Titans Memory-as-a-Layer blocks into a Decision Transformer so a neural memory module stores episodic information in fast weights updated across chunks. The paper introduces X-Maze, a controlled offline RL environment where the agent sees a sequence of instructions, waits, and later has to repeat them. DTi can learn dependencies at least 20 times longer than its context window and can extrapolate to waiting phases about 1.7 times longer than those seen in training. But the mechanism is not magic: performance depends on the observation encoding providing cues that can query earlier keys, more memory heads mostly increase the chance of a useful propagation path, momentum helps keep gradients alive, and long extrapolation is limited by catastrophic forgetting from repeated memory updates.

## Model definition

### Inputs

The model receives Decision Transformer trajectory tokens: returns-to-go, states, and actions. In X-Maze, states encode instruction observations, waiting signals, and repeat-phase cues. Sequences are processed in chunks, with persistent memory tokens appended to each chunk.

### Outputs

It predicts actions for discrete control. In X-Maze, actions correspond to instruction symbols plus a null waiting action.

### Training objective (loss)

The Decision Transformer action head uses the standard discrete-action classification objective. The Titans memory module updates fast weights through an inner self-supervised reconstruction-style objective, minimizing the squared error between memory output for a key and a value vector. Training is on full trajectories processed chunk by chunk, with no backpropagation through time across chunks.

### Architecture / parameterization

Decision Titan uses the Titans Memory-as-a-Layer architecture inside a Decision Transformer. Each MAL block applies a neural memory module followed by self-attention. The memory module is a two-layer MLP with fast weights updated by learned forget, momentum, and write gates. The paper tests chunked, global, and axial positional embeddings, plus different numbers of MLP memory heads.

## Key questions this summary must address

### 1. What problem is the paper trying to solve?

It asks whether offline RL models can use a long-term memory mechanism that scales beyond a Transformer's fixed context window, without simply increasing attention length.

### 2. What is the method?

The method merges Decision Transformer with Titans. It processes whole trajectories in chunks so the memory state rolls forward, inserts a TTT memory layer into one of three layers, and evaluates the resulting Decision Titan on controlled memory tasks.

### 3. What is the method motivation?

Sequential decision-making often requires remembering observations far outside the current context. Attention has quadratic scaling, and RNN-style vector states can be too compressed. TTT stores information in parameters updated at test time, offering a different memory substrate.

### 4. What data does it use?

The main experiments use X-Maze datasets of 10,000 trajectories generated by a perfect hard-coded policy. X-Maze varies instruction sequence length, waiting-period length, instruction count, and observation encoding. The paper also includes additional T-Maze experiments in the appendix.

### 5. How is it evaluated?

Evaluation measures mean episode return, where 0 is perfect and mistakes receive negative reward. The experiments test combinations of positional embeddings and observation encodings, number of memory heads, training waiting lengths, extrapolation to unseen waiting lengths, and memory-gate visualizations.

### 6. What are the main results?

DTi performs perfectly in one-hot repeat encoding and close to perfectly in one-hot signal, but struggles in single-signal encoding with mean returns around -5.6 to -5.76, still better than random -9. More memory heads reduce the training fraction needed to reach perfect return; with four heads the mean first-perfect fraction is 0.35 for [11,15], 0.37 for [46,50], and 0.71 for [96,100] waiting ranges. DTi generalizes to waiting phases at least 1.7x the training length in the best setting. Without momentum, success drops to 0% in waiting length 50 and 100 settings, versus 100% and 40% with momentum.

### 7. What is actually novel?

The novelty is applying Titans-style TTT memory to offline RL and pairing it with X-Maze plus mechanistic gate analysis. It is a study of memory behavior, not just a performance claim.

### 8. What are the strengths?

The controlled environment isolates sequential memory cleanly. The gate visualizations and momentum ablation help explain how the memory works. The paper is honest that cue availability, positional encoding, and memory corruption matter.

### 9. What are the weaknesses, limitations, or red flags?

X-Maze is a toy environment by design. Training on full trajectories is expensive and does not scale cleanly to very long episodes. DTi still falls off by around 200 steps, far short of external-memory methods like ELMUR in much longer T-Maze settings. The model has limited ability to remember order when the environment does not provide helpful recall cues.

### 10. What challenges or open problems remain?

The main challenge is avoiding catastrophic forgetting from repeated memory updates. Sparse memory access or more selective update rules may be needed. Another challenge is testing the mechanism in noisy, partially observable, high-dimensional environments rather than symbolic X-Maze.

### 11. What future work naturally follows?

Future work should combine TTT memory with sparse update schemes, relative positional representations, and harder long-horizon RL benchmarks such as MemoryMaze or robot memory suites. It should also compare directly against token-memory methods under equal compute.

### 12. Why does this matter for cabbageland?

Cabbageland cares about long-horizon decision-making and memory mechanisms. This paper gives a concrete warning that parameter memory is not automatically durable; it needs the right cues, update dynamics, and training protocol.

### 13. What ideas are steal-worthy?

The steal-worthy idea is X-Maze as a controlled probe for sequential memory order, capacity, and waiting-time extrapolation. The gate visualization is also worth copying for any fast-weight memory model.

### 14. Final decision

Preserve. This is a useful mechanism note for offline RL memory, with clear limitations and good diagnostic value.
