# Daily Paper Digest - 2026-08-25

## Theme

The good papers today all defend some structure that weaker systems would flatten away. **ReWorld** refuses to let short-horizon control erase revisit memory. **Correcting a learned physical invariant improves world-model rollouts** refuses to treat a decodable correlate as good enough unless the model's own dynamics preserve it. **Interpretable AI with Local Distillation** refuses to average local heterogeneity into one global explanation. **SWE Refactor Bench** refuses to confuse passing tests with actually performing the requested migration. **The Interaction Tax** refuses to assume that more agent communication automatically helps when the real effect can be diversity collapse.

## Short overview

This Tuesday, August 25, 2026 run inspected full arXiv HTML text for all five ranked papers below. All five are worth keeping, but the batch splits cleanly into two lanes. **ReWorld** and **Correcting a learned physical invariant improves world-model rollouts** are direct world-model papers about memory and dynamical integrity. **Interpretable AI with Local Distillation**, **SWE Refactor Bench**, and **The Interaction Tax** are adjacent papers that matter because they make hidden failure modes explicit instead of letting evaluation or coordination stay mushy. **Most relevant today:** **ReWorld: An Interactive World Model with Long-Horizon Memory**.

## Ranked papers

### 1. **ReWorld: An Interactive World Model with Long-Horizon Memory**

**Verdict:** must read direct paper.

Why it matters: This is the strongest paper in the batch because it names a real systems tension and then actually engineers around it. Control wants a short window, memory wants a long one, and ReWorld stops pretending one attention policy can cleanly serve both. The useful package is specific: mixed per-head attention windows, random head routing, a pose-indexed landmark bank under a fixed **12**-chunk KV budget, chunk-drop training so sparse caches are in-distribution, and LoRA-confined four-step distillation for real-time use. The result is not just architectural garnish: against six recent interactive world models it reports the best control fidelity at **11.95** degrees rotation error, the best camera-motion consistency, and minute-long out-and-back rollouts that still regenerate the starting view after **64** seconds and **384** latents.

### 2. **Correcting a learned physical invariant improves world-model rollouts**

**Verdict:** highly relevant direct paper.

Why it matters: This is a small but severe paper. Instead of asking whether a latent can decode something energy-like, it asks whether the model's own transition preserves that quantity and whether violating it actually harms imagined rollouts. On a frozen DreamerV3 trained only on pendulum video, a label-free search over degree-4 latent polynomials recovers a reproducible invariant in conservative models, not in matched damped ones. The comparative signal is hard to shrug off: the damped-model candidate varies about **2400x** more within trajectories, and the held-out invariance ratio moves from **0.0027-0.0121** in conservative models to **0.983-0.994** in damped ones. Projecting latent rollouts back toward the recovered level set cuts rollout error by **2.9%**, **3.3%**, and **3.5%** across the three conservative seeds, while matched random constraints usually hurt.

### 3. **Interpretable AI with Local Distillation**

**Verdict:** preserve-worthy adjacent paper.

Why it matters: This paper earns preservation because it does something better than attribution theater. A black-box teacher defines locality in prediction space and anchors a sparse linear student at each query point, so the explanation is the model, not a post hoc excuse pasted on top of it. The method is sharp in three places: teacher-defined neighborhoods, a pseudo-observation at the query point whose weight is estimated from the data, and randomized refits that turn feature selection into a stability object instead of a vibes object. The concrete examples are good. On Auto MPG, local distillation cuts prediction squared error from **10.81** for a global lasso to **5.59**, nearly matching the TabPFN teacher at **5.25**. In the BRCA1 gene-expression example, local models keep a median of **15** stably selected genes and surface subgroup-specific signals that the global lasso flattens to zero.

### 4. **SWE Refactor Bench: Can Coding Agents Complete a Long-Horizon, Whole-Repository Stack Migration?**

**Verdict:** preserve-worthy adjacent paper.

Why it matters: This is the best coding-agent evaluation paper in the batch because it attacks a real benchmark failure mode instead of decorating the old ones. The central claim is simple and right: passing tests is not the same thing as performing the migration, and a benchmark that only checks behavior can reward agents for copying the old implementation. The three-stage protocol is the useful part: Migration Audit checks whether the migration happened, Behavioral Tests check whether it still works, and Agentic Verification sends **6** independent coding agents to look for hidden failures. The results are brutal enough to matter: only **28** of **520** runs (**5.4%**) pass all three stages, **13** of **20** tasks get no accepted solution, and the best model scores only **47.0/100**. Among the **340** runs that clear Migration Audit, **58%** get to **99%** of fixed checks but only **26%** get to **100%**, which is exactly the kind of "almost right" failure that a serious benchmark should expose.

### 5. **The Interaction Tax: When Communication Erases Diversity in Multi-Agent Teams**

**Verdict:** preserve-worthy adjacent paper.

Why it matters: The useful move here is not "multi-agent good" or "multi-agent bad." It is the narrower claim that full-solution communication is often the wrong thing to share because it collapses the diversity that made multiple agents worth using in the first place. On **11** verifier-scored optimization tasks with matched budgets, the paper shows that same-model teams can sometimes benefit from interaction, but diverse-model teams often get worse once they read each other's full outputs. In the controlled factorial, model diversity itself has a positive coefficient of **+0.188** with confidence interval **[+0.073, +0.299]**, while synthesis is near zero. The paper's best concrete diagnostic is that Chain, MAgICoRe, and Debate all turn negative for diverse teams, while MoA escapes the interaction-tax zone because the proposers stay independent until selection.

## Most relevant to cabbageland

**Most relevant today:** **ReWorld: An Interactive World Model with Long-Horizon Memory**.

It is the most direct hit on current cabbageland interests because it takes a recurrent problem in world-model talk - "just add memory" - and decomposes it into actual systems constraints. The paper's real contribution is not merely a longer context window. It is the separation of short-horizon action following from long-horizon revisit memory, plus the fixed-budget memory policy that makes that separation deployable.

The rest of the batch rhymes with the same standard. The invariant paper says a world model should preserve meaningful structure in its own latent dynamics, not merely decode it. Local Distillation says if you want interpretability, the explanation object should still track local predictive structure instead of averaging it away. SWE Refactor Bench says evaluation should not collapse "did the requested transformation happen?" into "did the tests pass?" Interaction Tax says multi-agent systems should not erase proposal diversity just because communication feels principled.

## Novelty / framing / baseline impact

**ReWorld** matters because it treats control-memory conflict as a systems-design problem with separate training windows and fixed-budget retrieval, not as generic context stuffing.

**Correcting a learned physical invariant improves world-model rollouts** matters because it upgrades "latent probes" into a stronger question: does the transition preserve the quantity, and does enforcing it improve rollouts?

**Interpretable AI with Local Distillation** matters because it makes locality teacher-defined and prediction-grounded, then adds randomized stability instead of pretending one local fit is self-authenticating.

**SWE Refactor Bench** matters because it makes migration completeness a first-class evaluation object rather than an assumption hidden behind behavioral tests.

**The Interaction Tax** matters because it isolates communication content as the key variable: the number of agents is not the point if the information exchange destroys diversity after one round.

## One-paragraph takeaway

The August 25 lesson is that many systems fail by collapsing the very distinction that matters. ReWorld keeps long-horizon spatial evidence alive instead of forcing it through a short control window. The invariant paper distinguishes "predictable from pixels" from "preserved by dynamics." Local Distillation distinguishes global fit from local structure. SWE Refactor Bench distinguishes behavioral correctness from objective completion. Interaction Tax distinguishes having many agents from preserving many approaches. Same rule everywhere: if the system averages away the informative difference, the benchmark may still smile while the mechanism quietly dies.
