## Short overview

Brave Search was unavailable in this run because the current environment is missing a Brave API key, so discovery was narrower than usual and relied on direct recent arXiv inspection. I fetched accessible arXiv pages and inspected substantial arXiv HTML for **An Agentic System for Scalable Articulated 3D Asset Generation**, **Hand-in-the-Loop: Improving Dexterous VLA via Seamless Interventional Correction**, **Evo-Depth: A Lightweight Depth-Enhanced Vision-Language-Action Model**, and **A Unified Embodied Intelligence Model for Understanding, Reasoning, Imagination and Action**. Confidence is strongest on the high-level mechanism and contribution framing, and weaker on appendix-level ablations because I did not fully audit the later experimental sections.

**Articraft** is the most relevant paper today. Its core move is to reduce articulated-object generation to writing a single executable program against a deliberately narrow SDK, then let an LLM iterate inside a harness that validates geometry, articulation, and tests. That is much better than the usual "agentic 3D" mush because the representation does real work: the asset is code, joints are explicit, and failures are exposed through a structured execution environment rather than aesthetic human preference.

**Hand-in-the-Loop** is good adjacent robotics work. The useful contribution is not just "human in the loop" branding. It specifically addresses gesture jumps when a human takes over a dexterous policy mid-rollout by mapping *relative* fingertip motion at takeover time instead of snapping to the operator’s absolute hand pose, while arm corrections are injected as residual twists. That is a real systems mechanism for harvesting on-policy correction data without destroying the current grasp.

**Evo-Depth** is a respectable efficiency paper, but I would keep the enthusiasm calibrated. The idea is to inject lightweight implicit depth features from multi-view RGB into a 0.9B VLA through a modulation module rather than through a heavier explicit 3D stack. That is practically useful, especially if the reported memory and latency numbers hold up, but conceptually it is still a retrofit of spatial bias into an otherwise standard VLA pipeline.

**Pelican-Unified**, despite the grand claims, mostly reads like unification rhetoric plus a large shared stack. I did not preserve a note for it because the accessible text leaned much harder on manifesto framing than on a crisp new computational contract.

## Most relevant to cabbageland

**Most relevant today:** Articraft.

The useful part is not that it uses an LLM to make 3D stuff. Plenty of papers already do that in decorative ways. The useful part is that it makes the artifact itself legible and revisable by forcing generation through a constrained program with named parts, articulation objects, motion limits, and test hooks. That means the agent is not merely sampling geometry. It is authoring an explicit object model inside an environment that can say what failed.

That matters for cabbageland because it points to a broader design rule: if you want generative systems to produce reusable structure, give them a representation that supports decomposition, validation, and repair. The main caveat is that this is still synthetic data generation rather than learned embodied interaction, so the relevance is more about representation and agent harness design than about direct robot policy learning.

## Novelty / framing / baseline impact

The main framing update is that **"agentic" work becomes much more credible when the agent edits an executable structured object representation inside a narrow feedback loop**. Articraft is a useful rebuttal to both one-shot text-to-3D hype and to heavyweight pipelines that need Blender or image-based critique just to stay on the rails.

Hand-in-the-Loop sharpens a different point. If dexterous VLAs are going to learn from intervention, the intervention interface itself is part of the method. Abrupt authority transfer can destroy the very contacts you are trying to preserve, so relative retargeting and residual shared control deserve to be treated as core mechanism, not user-interface detail.

Evo-Depth mostly affects baselines and design priors. It suggests that some of the recent rush toward heavy geometry foundations for VLA spatial grounding may be overkill when a lighter implicit-depth path can buy a decent chunk of the gain.

## One-paragraph takeaway

The best paper today is **Articraft** because it gives the "agentic 3D generation" story an actual computational spine: explicit parts, explicit joints, explicit tests, and a harness that turns failure into structured repair rather than vibes. **Hand-in-the-Loop** is the strongest adjacent robotics paper because it solves a real takeover problem in dexterous intervention and turns that fix into better on-policy correction data. **Evo-Depth** is useful but narrower, a plausible lightweight depth bias for VLAs rather than a major representational shift. The broader lesson is that embodiment papers get more interesting when they stop chanting unification and start specifying the representation, control interface, or validation loop that really constrains the system.
