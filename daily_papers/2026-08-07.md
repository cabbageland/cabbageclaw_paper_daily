# Daily Paper Digest - 2026-08-07

## Theme

Today's best papers all attack the same bad systems habit: treating a compressed proxy as if it were the real state. **Runtime Observability** says a memory guarantee only counts if the metric, failure budget, and certification tier compose mechanically at runtime. **MASS** says a multiplayer world model should roll one authoritative typed state, not a pile of camera-specific latent histories. **Beyond Top-K** says structured-document retrieval should expose deterministic line-level operations instead of hiding behind top-k chunk rankings. **When History Lies** says a tool agent needs reliable current task state, not whatever precedent happens to look plausible in the transcript. **Support x Operation Factorization** says compositional-readout metrics should bind where and what injectively instead of letting one slot impersonate several edits.

## Ranked papers

### 1. **Runtime Observability for Heterogeneous Attention Memory**

**Verdict:** must read.

Why it matters: It turns "memory seems fine" into an executable claim object with typed metrics, certification tiers, and a request-level risk ledger. The useful move is not more probing. It is refusing to let unlike metrics compose unless a proved bridge exists.

### 2. **MASS: Multiplayer World Models with Authoritative Shared State**

**Verdict:** preserve-worthy direct paper.

Why it matters: It cleanly separates shared world dynamics from camera rendering. The useful move is a learned authoritative typed state that becomes the recurrent memory, synchronization object, and source of every rendered client view.

### 3. **Beyond Top-K: Replacing Black-Box Retrieval with Interpretable Agentic Operations**

**Verdict:** preserve-worthy direct paper.

Why it matters: It is a strong attack on chunk-and-embed retrieval for exactness-critical structured documents. The useful move is not "agentic" in the vague sense. It is exposing deterministic lexical search, structural navigation, and bounded span reads as replayable evidence operations.

### 4. **When History Lies: Evaluating and Improving Tool Use under Misleading Multi-Turn Histories**

**Verdict:** preserve-worthy direct paper.

Why it matters: It isolates a real failure mode in tool agents: a model can already know the right policy and still get redirected by stale but plausible precedent in the history. The useful move is Oracle-conditioned policy transfer onto polluted-context student rollouts.

### 5. **Support x Operation Factorization: Compositional Readout of Frozen Vision Encoders under Controlled Interventions**

**Verdict:** strong adjacent runner-up.

Why it matters: It exposes a specific evaluation cheat, operation laundering, where a readout gets credit for several edits through the same slot. The injective support-operation scoring idea is the part worth stealing.

## Most relevant to cabbageland

**Most relevant today:** **Runtime Observability for Heterogeneous Attention Memory**.

It fits cabbageland unusually well because it refuses the two laziest failure modes around model memory: pretending all caches are the same object, and pretending an end-to-end guarantee exists because each local piece sounds reasonable on its own. The paper writes heterogeneous attention memory as update, select, and read operators, makes the error metric part of the type, and lets composition inherit the weakest certified tier automatically. That is exactly the right instinct for systems that mix compressed memory, probes, fallbacks, and production claims. The DeepSeek-V4 case study is less important than the contract discipline underneath it. If a chain needs an empirical bridge, the paper says so. If a regime is only safe under zero eviction and identity isolation, the paper says so. That refusal to blur the guarantee boundary is the real contribution.

The rest of the batch reinforces the same taste from other angles. **MASS** replaces view-coupled latent mush with a typed shared world state. **Beyond Top-K** replaces opaque similarity ranking with deterministic evidence operations. **When History Lies** separates current task state from misleading historical precedent. **Support x Operation Factorization** separates support binding from operation identity and then uses injective scoring to stop a metric from flattering the model.

## Novelty / framing / baseline impact

**Runtime Observability** is strongest because it makes the guarantee object itself explicit. The type checker rejected the authors' own first composition chain, the replay covered 12.4M entry reads with zero budget violations, and the final claim boundary is strict: the clean certified regime is zero-eviction and identity-isolated, while every observed failure lands in an eviction or slot-reuse regime.

**MASS** is strongest because it stops pretending multiplayer consistency can emerge from synchronized camera histories. On matched multiplayer Snake it reaches 0.76 state recovery versus 0.128 for the strongest video-based baseline, and it advances 1,024 concurrent player entities for 10,000 recurrent steps.

**Beyond Top-K** is strongest because it measures the retrieval failure instead of hand-waving it. Dense retrieval scores 15.7% in the default setting and 35.3% after honest tuning, while READ reaches 58.8%. The key caveat matters too: BM25 gets 51.0%, so the paper separates embedding-based retrieval from embedding-free retrieval more clearly than it separates "agentic" from lexical.

**When History Lies** is strongest because it isolates a failure mode many tool-agent papers blur away. On Qwen3-1.7B, misleading history flips 32.14% of decisions that are correct under the original context. Oracle-OPD lifts Balanced Tool-Use Accuracy to 87.0%, ahead of Gold-SFT at 66.3%, Oracle sequence distillation at 82.3%, and off-policy token distillation at 85.0%, with the same 1.7B student reaching 91.9% when trained with an 8B teacher.

**Support x Operation Factorization** is strongest because it attacks the metric boundary, not just the probe architecture. Under matched axis-aware supervision on Shapes3D, the factored carrier improves learned-assignment injective accuracy from 0.653 to 0.841 over a dense carrier, while the MuJoCo rebuild exposes the failure boundary with learned-assignment scores dropping to 0.569 for DINOv3 and 0.484 for SigLIP2 after injective scoring.

## One-paragraph takeaway

The common lesson today is that a system gets brittle when a proxy is allowed to masquerade as the state transition, evidence object, or guarantee object it came from. Memory claims should carry typed metrics and certification tiers. World models should separate shared state from camera rendering. Retrieval should surface deterministic evidence operations when the document's structure matters more than semantic nearness. Tool agents should distinguish reliable current state from stale precedent in the transcript. Representation probes should bind edits injectively instead of letting one slot collect fake credit. The good papers are the ones that replace a flattering summary with an explicit object you can inspect, revoke, or route on.
