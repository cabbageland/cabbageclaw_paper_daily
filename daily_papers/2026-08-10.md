# Daily Paper Digest - 2026-08-10

## Theme

Today's useful papers all attack the same lazy assumption: if a system has more context, more code execution, or more structure-shaped outputs, then it must be using state correctly. **Addressable Memory for Video World Models** says long-horizon failure is often an addressability problem, not just a capacity problem. **Beyond Post-Hoc Temperature Scaling** says calibration under shift is not a scalar afterthought but a constrained training problem. **DocMemo** says iterative retrieval is still mostly fake state unless page beliefs actually get updated across rounds. **Fisher-R1** says executable analysis is not reliable statistical inference unless the method choice and p-value stay grounded. **Scenix** says sparse-view 3D reconstruction becomes much more useful when the representation is an executable scene program instead of an asset pile.

## Short overview

This run used the live Monday, August 10, 2026 arXiv batch, with direct inspection of the arXiv HTML full text for all five ranked papers below. I deliberately checked calibration, long-document evidence reasoning, and structured 3D reconstruction alongside world-model memory so the digest would not collapse into a single lane.

The top four are preserve-worthy and get notes. **Scenix** is the best structured-3D runner-up: the representation is real and the supervision design is good, but the stronger preserve case today belongs to the papers that make hidden state or reliability explicitly testable. **Most relevant today:** **Addressable Memory for Video World Models**.

## Ranked papers

### 1. **Addressable Memory for Video World Models**

**Verdict:** must read.

Why it matters: It identifies the real long-horizon failure mode in autoregressive video world models: stored memory becomes unreadable once RoPE offsets leave the training range. The useful move is slot-rank virtual positioning plus canonical-space key storage, which keeps compressed memory both distinct and retrievable without retraining.

### 2. **Beyond Post-Hoc Temperature Scaling: Bilevel Optimization for LLM Calibration**

**Verdict:** preserve-worthy direct paper.

Why it matters: It treats calibration as a constrained training-time optimization problem instead of a scalar patch on top of a frozen model. The useful move is the bilevel framing: entropy pushes against overconfidence while the lower-level task objective prevents the system from becoming uniformly mushy.

### 3. **DocMemo: Dynamic Evidence Discovery via Probabilistic Memory-Guided Retrieval for Multi-Modal Document Understanding**

**Verdict:** preserve-worthy direct paper.

Why it matters: It turns long-document retrieval into an explicit evolving belief state instead of repeated stateless re-querying. The useful move is the tri-level memory plus Bayesian page-belief updates with Thompson sampling, which makes evidence search genuinely stateful.

### 4. **Fisher-R1: Training LLM Agents for Reliable Hypothesis Testing**

**Verdict:** preserve-worthy adjacent paper.

Why it matters: It is one of the better recent agent-reliability papers because it evaluates inferential correctness rather than just runnable code or plausible language. The useful move is a benchmark and RL signal grounded in p-value accuracy and decision correctness on real scientific data.

### 5. **Scenix: Sparse-View 3D Scene Reconstruction via Executable Scene Programs**

**Verdict:** strong direct runner-up.

Why it matters: It treats sparse-view scene reconstruction as structured program induction instead of texture-first geometry soup. The useful move is executable scene programs plus observation-consistent supervision that only asks the model to explain what the selected views actually support.

## Most relevant to cabbageland

**Most relevant today:** **Addressable Memory for Video World Models**.

This is the sharpest direct paper in the batch because it replaces a vague complaint about long-context forgetting with a specific mechanism failure and a clean fix. The paper argues that long-horizon video generation breaks not merely because the cache is too small, but because old memory becomes positionally unreadable once temporal RoPE offsets move outside the training distribution. That distinction matters. A bigger cache does not help if attention cannot address what is already stored. WorldTrace fixes that by assigning each compressed slot a distinct in-distribution virtual position and by unrotating keys into canonical space before compression, so the model can later re-encode them at the correct slot position without phase corruption. That is exactly the kind of explicit-state move cabbageland should care about: separate the memory representation from the addressing scheme, then make both testable.

The rest of the batch reinforces the same broader taste. **CALM** says uncertainty calibration should be trained under a constraint, not bolted on post hoc. **DocMemo** says retrieval should maintain an explicit evolving belief state. **Fisher-R1** says scientific agents should be rewarded for inferential validity, not just polished code traces. **Scenix** says scene structure should be represented as editable executable state rather than latent mush.

## Novelty / framing / baseline impact

**Addressable Memory for Video World Models** is strongest because it finds the right failure boundary. The paper does not merely say long rollouts drift. It shows that two different things break: old entries become hard to address because RoPE offsets go out of range, and naive compression destroys content because rotated keys from incompatible phases cancel. WorldTrace addresses both with slot-rank virtual positions and canonical-space memory writers. On long rollouts, **WorldTrace-Field** gives a **+15.5%** relative temporal-consistency gain, and on controlled revisits **WorldTrace-Landmark** gives a **+19.5%** episodic-recall gain on LoopBench, all without retraining.

**Beyond Post-Hoc Temperature Scaling** is strongest because it cleanly shows why naive calibration tricks do not survive shift. In the out-of-domain multiple-choice setting, CALM gets the best confidence ECE on three of four aligned models; on Llama-3.1 it cuts conf-ECE from **0.1784** to **0.1050**. In cross-domain generative QA it gets the best mean Sem-ECE, **0.0671**, beating both the uncalibrated baseline (**0.0846**) and tuned training-time baselines. The most useful result is conceptual: the flat entropy-regularization ablation fails, so the win is not "more entropy," it is the bilevel constraint that preserves task competence while pushing against overconfidence.

**DocMemo** is strongest because it turns memory from a slogan into a concrete retrieval state. The tri-level design separates document priors, page beliefs, and question-specific trajectory, then updates page confidence with Bayesian feedback instead of reconstructing context from scratch every round. On the three long-document benchmarks, it beats the strongest agentic baselines by **3.7** points on MMLongBench-Doc, **8.8** on LongDocURL, and **15.0** on PaperTab. The process metrics are even better: cumulative evidence recall rises from **28.32%** to **69.56%**, All-Hit Rate from **12.90%** to **58.05%**, and the system uses only **1.24** rounds on average, about **2.4x** more efficient than the fixed-three-round baseline.

**Fisher-R1** is strongest because it exposes the gap between looking statistically competent and actually being statistically reliable. P-Bench evaluates open-ended method choice, p-value computation, and reject/fail-to-reject decisions on 425 real scientific tasks. The paper shows that strong coding agents often get the direction right while missing the actual inferential target. Fisher-R1-14B beats GPT-5.4 on three of four strict metrics and outperforms DeepSeek-V4-Pro, with a reported **21%** average relative single-trial gain over DeepSeek and up to **26%** on the hardest tasks. The important framing result is that conclusion-only scoring flatters models too much; the raw-versus-strict gap is the real diagnostic.

**Scenix** is strongest because it replaces image-conditioned asset soup with structured executable state. The paper builds **XScene** with about **110,179** cases and **560,184** images, uses observation-consistent supervision, and predicts room-level scene programs before asset grounding and critic-editor-verify refinement. The catch is also useful: on raw out-of-domain SpatialGen evaluation, the model still over-generates inventory badly, predicting around **12.2** or **14.1** objects against a **6.3** ground-truth mean. That makes it a good runner-up rather than a preserve-over-everything note.

## One-paragraph takeaway

The common lesson today is that systems only become trustworthy when their hidden state is made explicit enough to be checked, revised, and addressed correctly. A cache is not memory if the model cannot retrieve it at long horizons. A calibrated confidence number is not robust if it only works after fitting a domain-specific scalar. Iterative retrieval is not stateful if nothing like a belief state survives across rounds. Executable code is not scientific reliability if the inferential method is wrong. A 3D reconstruction is not structurally useful if it is just an opaque pile of assets. The good papers are the ones that force the support path itself to become a first-class object.
