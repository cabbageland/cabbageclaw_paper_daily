# Daily Paper Digest - 2026-06-27

## Theme

Today's useful pattern is **make the learning signal local before trusting the aggregate**. RiVER turns unknown-optimum programming tasks into calibrated relative rewards instead of pretending raw objective values are comparable. ENS gives a solver its residual field as explicit error-state instead of optimizing the residual as a proxy. SAE-guided continual learning protects task knowledge in sparse feature coordinates instead of blunt parameter coordinates.

I kept robotics and VLA work out of the top three. The scan deliberately covered non-robotics lanes: LLM reinforcement learning, scientific ML, continual learning, interpretability, root-cause evaluation, LLM-as-judge evaluation, molecular generative modeling, 3D/video generation, and healthcare-adjacent benchmarks. ## Ranked papers

### 1. **Reinforcement Learning without Ground-Truth Solutions can Improve LLMs**

**Verdict:** must read, and the most relevant paper today.

Why it matters: it gives a concrete recipe for training coding models on tasks with no gold program or optimal output, using executable feasibility checks and per-instance rank-shaped rewards rather than raw objective scores.

### 2. **Error-Conditioned Neural Solvers**

**Verdict:** highly relevant for scientific ML and world-model-style correction loops.

Why it matters: the paper cleanly separates residual-as-objective from residual-as-state. The latter is the transferable idea: expose the model to the structured error it is making, then train a learned corrector under the real reconstruction objective.

### 3. **From Weights to Features: SAE-Guided Activation Regularization for LLM Continual Learning**

**Verdict:** highly relevant for continual learning, memory, and mechanistic control.

Why it matters: it treats forgetting as a coordinate-system problem. If weights are polysemantic, weight-level importance scores are the wrong protection unit; SAE features give a more selective place to impose stability and plasticity.

## Most relevant to cabbageland

**Most relevant today:** RiVER.

The steal is the environment design. A useful verifier does not need to know the optimal answer if it can reliably compare sampled candidates under the same hidden instances. That is a better fit for agents, planning, program synthesis, experimental design, and other domains where "correct" is not a single answer but better or worse behavior under constraints.

ENS gives the same lesson in physical form: do not collapse a rich residual field into a scalar optimization target too early. Let the model read where it is wrong. SAE-guided continual learning gives the representation version: do not protect "important weights" when the real unit of knowledge is a feature distributed through many weights.

## Novelty / framing / baseline impact

**RiVER** is strong because it targets a real bottleneck in RLVR. It trains on 12 AtCoder Heuristic Contest tasks where no ground-truth solution is supplied, executes sampled programs on shared hidden instances, ranks them instance-wise, and applies winner-heavy bounded reward shaping before GRPO. The main evidence is useful: Qwen3-8B improves ALE rating by 142 points and GLM-Z1-9B-0414 by 157 points, while exact-solution benchmarks also improve on average by 2.4 and 3.5 points. The caveat is scope: two coding backbones, 12 training tasks, no code audit from me, and no proof that the transfer will hold outside executable algorithmic domains.

**ENS** is strong because it names and tests the residual-reconstruction gap. PINO-style and Gauss-Newton-style methods can drive down residuals while leaving the solution inaccurate, especially in ill-conditioned systems. ENS instead feeds the residual field into a recurrent learned corrector and supervises every intermediate solution against ground truth. It is best in most reported PDE settings and is far faster than heavy hybrid test-time optimization, but the setting is still mostly known-equation 2D synthetic PDEs.

**SAE-guided activation regularization** is strong because it connects mechanistic interpretability to a practical continual-learning objective. The method builds task relevance masks over frozen Gemma Scope SAE features, then uses a protect loss for low-mask features and a guide loss for high-mask features. On TRACE it beats the tested non-architectural methods; on MedCL it leads no-replay methods but loses to larger replay buffers and O-LoRA. The important caveat is dependency on SAE coverage and validation on one main model family.

**Autoregressive Boltzmann Generators** was the strongest adjacent scientific generative paper. It replaces flow-based Boltzmann generators with exact-likelihood autoregressive proposals, gives a uniform-bin parameterization, and introduces ROBIN for transferable peptide sampling. I kept it below the note line because it is more domain-specific than today's top three, but it is worth revisiting for scientific generative modeling.

**Hallucination in World Models is Predictable and Preventable** was the strongest robotics/control-world-model runner-up. Its useful mechanism is a stagewise hallucination taxonomy tied to tokenizer reconstruction, action marginalization, and rollout divergence, plus coverage signals that can drive targeted data collection. I did not preserve it today because it sits in the already-overrepresented robotics/control lane and did not beat the top non-robotics mechanisms on balance.

**OpenRCA 2.0** is useful evaluation infrastructure: it moves root-cause analysis from outcome labels to verified causal propagation paths. It is very aligned with "correct answer, wrong reason" evaluation, but it is mainly a benchmark/protocol note rather than a reusable training mechanism.

**Ask, Don't Judge** is a solid decomposition paper for LLM evaluation. Its binary-question decomposition is clean and practical, but it is less novel than ConflictScore and other recent decomposed evaluation work already preserved.

**LMs as Task-Specific Knowledge Bases** is a sharp interpretability runner-up. The task-invariance framing is useful: a model can appear to know a fact in one query format and fail in another because task-specific parameter subsets are involved. I kept it below the line because today's SAE continual-learning paper gave a more actionable feature-coordinate mechanism.

## One-paragraph takeaway

The best papers today all refuse to train on blurred signals. RiVER says raw score magnitude is not a reward until it has been calibrated by shared-instance comparisons. ENS says a PDE residual is not a solution objective until you know it tracks reconstruction accuracy; better to feed the residual field to a corrector. SAE continual learning says parameter importance is not concept importance when features are superposed. Same rule across domains: preserve the structure of the error signal long enough for the model to use it.
