# Daily Paper Digest - 2026-06-26

## Theme

Today's useful pattern is **aggregate scores hide the failure surface**. A saturated benchmark can still reveal scaffold dependence, unreliable confidence, cost differences, and human-agent uplift. A factuality metric that collapses all retrieved evidence into one corpus misses the case where some sources support a claim and others contradict it. A model-diffing tool that reports reconstruction fidelity can miss the single feature that actually gates tool use.

## Ranked papers

### 1. **Life After Benchmark Saturation: A Case Study of CORE-Bench**

**Verdict:** must read, and the most relevant paper today.

Why it matters: it is a clean antidote to accuracy-only agent evaluation. When top agents tie near the ceiling, the benchmark can still expose whether the agent is validly solving the task, how much scaffold matters, how reliable and efficient the system is, and whether it actually helps humans.

### 2. **ConflictScore: Identifying and Measuring How Language Models Handle Conflicting Evidence**

**Verdict:** highly relevant for RAG, memory, and factuality evaluation.

Why it matters: it makes disagreement inside retrieved evidence measurable at the claim-document level, then shows that conflict feedback can improve TruthfulQA answers while prompt-only balancing gives limited leverage.

### 3. **Localizing RL-Induced Tool Use to a Single Crosscoder Feature**

**Verdict:** highly relevant for mechanistic interpretability of agentic behavior.

Why it matters: it suggests that at least some post-training-installed agent skills can condense into sparse, steerable internal features rather than living only as diffuse behavioral changes.

## Most relevant to cabbageland

**Most relevant today:** Life After Benchmark Saturation.

The steal is the measurement frame. Once headline accuracy saturates, do not throw the benchmark away by reflex. First ask whether stronger agents reveal validity bugs, shortcuts, scaffold sensitivity, confidence failures, compute inefficiency, out-of-distribution gaps, or human workflow uplift. Those are often the parts that matter for deployment.

ConflictScore gives the evidence version of the same lesson. Do not ask only whether an answer has support somewhere in the retrieved context. Ask whether the answer acknowledged the contradictory evidence it was also shown.

The crosscoder tool-use paper gives the internal version: do not trust reconstruction metrics alone. A representation can reconstruct well while the behaviorally decisive signal lives in a tiny feature subset.

## Novelty / framing / baseline impact

**Life After Benchmark Saturation** is strong because it does not merely complain about benchmark saturation. It repairs CORE-Bench Hard into CORE-Bench v1.1, builds a 19-task CORE-Bench OOD suite, and then asks what else can still be measured. The main practical results are useful: top agents cluster near 97% to 100% accuracy, Codex CLI with GPT-5.4 medium beats CORE-Agent with the same model by roughly 44 points on v1.1, agents report confidence far below their empirical pass rate, and a small randomized human-agent study estimates manual sessions took 2.11 times as long as human-agent sessions. The caveat is real: the uplift study has only 20 papers, 5 participants, no independent ground-truth reproduction outcome, and non-representative reproducers.

**ConflictScore** is useful because it changes the unit of factuality from "does the corpus support the claim?" to "which documents support, contradict, or ignore each atomic claim?" This distinguishes ordinary support from unresolved conflict. On a ConflictingQA slice, stronger conflict-aware prompts only modestly change model behavior, suggesting prompt prose is not enough. On TruthfulQA, conflict-aware regeneration improves multiple-choice accuracy across the reported models; on conflict-detected subsets, originally wrong answers are corrected much more often than originally correct answers are harmed. The main caveats are cost, claim-decomposition sensitivity, evidence-labeling errors, and the current lack of source-reliability weighting.

**Localizing RL-Induced Tool Use** is sharp but narrow. The paper trains 48 crosscoder variants over a ToolRL-fine-tuned Qwen2.5-3B pair and finds that post-reconstruction improves the RL model's tool correctness by 31.1 points on average, while a frozen base model gains 6.8 points of tool correctness through capability spillover. The most striking result is steering: one A-exclusive feature at layer 13 raises tool correctness by 65 points in the reported cell, and the effect generalizes across most probed layers. The caveat is scope: one model pair, one tool-call behavior, 100 held-out prompts per sweep variant, 40 prompts per steering cell, and no claim that all RL-induced agent skills will localize this cleanly.

**Detecting and Controlling Sycophancy with Cascading Linear Features** was the strongest safety-control runner-up. It uses graded behavior generation plus SAE feature selection to find sycophancy features that scale monotonically and can be used for detection and steering. I kept it below the note line because the crosscoder tool-use paper was a cleaner agentic-behavior mechanism today, but CLiF is worth revisiting for behavior-control tooling.

**The Verification Horizon** is an important field report from the Qwen team. Its main message is right: coding-agent reward design needs co-evolving verifiers, not one fixed reward. I kept it as framing rather than a preserved note because it is broad, partly internal-benchmark-driven, and less crisp as a single transferable mechanism than CORE-Bench.

**Just how sure are you?** is the strongest medical calibration runner-up. Its 2 by 2 image/text perturbation training signal and composite calibration loss are useful, and the reported calibration reductions are large. I kept it below the line because it is a domain-specific training method, while ConflictScore is more immediately reusable for agent evidence handling.

**CORTEX** is a useful medical benchmark resource: it restores 3D chest CT reasoning as four clinical stages and adds stage-level rubrics. It is more dataset construction than tested model mechanism, so it stays as adjacent healthcare infrastructure.

**Memory Depth, Not Memory Access** and **Temporal Validity in Retrieval Memory** both line up with recent Paper Daily memory themes. I kept them below the line to avoid repeating yesterday's source-versus-conclusion story. Memory Depth is an interesting synthetic split between retrieval access and parametric goal persistence, but it is narrow and its stale-memory boundary is explicitly unresolved. Temporal Validity has a strong deterministic supersession idea for structured mutable facts, but the current claim depends on structured single-value templates and extraction quality.

**When Does Combining Language Models Help?** and **The Capability Frontier** pull in opposite directions on routing. The former says the all-models-wrong tail bounds model orchestration; the latter says single-model benchmarks understate achievable frontier performance. The useful synthesis is that routing value depends on heterogeneity, co-failure, cost, and whether a real router can approach the oracle. Neither beat today's top three, but both sharpen evaluation framing.

## One-paragraph takeaway

The best papers today all reject the easy aggregate. **Life After Benchmark Saturation** says saturated accuracy is not saturated evaluation. **ConflictScore** says a supported answer can still be misleading if it ignores contradictory retrieved evidence. **Localizing RL-Induced Tool Use** says reconstruction quality is not enough; the behavior may be controlled by a sparse feature hidden inside the representation. Same rule across levels: measure the thing that can fail, not the headline number that stays smooth while the failure moves underneath.
