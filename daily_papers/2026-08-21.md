# Daily Paper Digest - 2026-08-21

## Theme

The good papers today all refuse to confuse stored artifacts with live state. A memory system is not the same thing as the current world state it is supposed to preserve. A step-level credit score is not the same thing as causal contribution. A benchmark score is not the same thing as a real repository improvement unless integrity checks survive contact with the code. A compliant action filter is not the same thing as a workflow-level policy path. A monolithic predictive embedding is not the same thing as a structured latent state.

## Short overview

This Friday, August 21, 2026 run used arXiv HTML full-text inspection for all five ranked papers below. Four papers earn preserved notes. **Orthogonal JEPA** stays just below the preserve bar because the factorized predictive-state idea is real and useful, but the current evidence is still broad and cross-domain rather than anchored in one especially harsh planning or long-horizon setting. **Most relevant today:** **Can Agent Memory Systems Track Evolving State?**

## Ranked papers

### 1. **Can Agent Memory Systems Track Evolving State?**

**Verdict:** must read direct paper.

Why it matters: This is the cleanest memory paper in the batch because it names the right target. Recall is not enough; the live problem is whether an agent can answer from the current state after earlier facts have been superseded. The paper builds **StateMemBench** with **234** multi-session scenarios and then shows a state-first memory design with explicit supersession and dependency tracking improves current-state accuracy from **0.205 -> 0.363** on DeepSeek-V4-Flash and from **0.149 -> 0.233** on Qwen-3.5-9B. The wrapper result is the sharp part: the same state structure lifts existing memory and retrieval backends by **+32 to +67** points, with a length- and cost-matched control attributing **+15 to +32** of that gain to state structure rather than extra context.

### 2. **Credit Without Ground Truth: Auditing Step-Level Credit Assignment in LLM Agents Against Executed Replay**

**Verdict:** must read direct paper.

Why it matters: This is the most severe evaluation paper in the batch because it stops grading credit signals against annotated step correctness and instead audits them against executed replay, meaning whether resampling the policy's own alternatives actually changes the outcome. Under that audit, the commonly used signals all collapse. Causal contribution is sparse at only **30.5%** of defined decision points, measurability differs sharply across policies (**13.1% vs. 26.8%** of points lack policy-supported counterfactuals), implicit credit mostly tracks fluency instead of causality (median rank correlation **+0.75**, replicated at **+0.70**), and outcome conditioning adds essentially no causal information (partial correlation **-0.004**). Even the training story gets punctured: no seven-arm training condition reliably beats the untrained policy once dose is matched.

### 3. **DeltaML-Bench: Evaluating Machine Learning Agents on Real-World Research Repositories**

**Verdict:** preserve-worthy direct paper.

Why it matters: This paper is strong because it makes autonomous ML experimentation pay the real repo tax instead of hiding inside toy harnesses. The benchmark uses **48** imperfect research repositories and asks agents to improve published baselines under compute budgets, with integrity checks explicitly built in so metric gains are not trusted by default. The scaffold result is large and concrete: under the **4 x 6h** allocation, ARG raises GPT-5 per-run success from **9.4%** to **33.9%**, and under **2 x 12h** it reaches **49.0%**. The more important systems result is negative: Modular configurations show specification gaming as high as **47.9%**, while the evaluated ARG setups show none.

### 4. **PolicyGuide: From Guarding One Action to Guiding the Whole Workflow for Policy-Compliant LLM Agents**

**Verdict:** preserve-worthy direct paper.

Why it matters: Most compliance systems only swat down obviously bad actions. This paper does something better: compile domain policy into a workflow graph, persist graph state across turns, and use a proactive verifier that returns step-specific remediation before the agent drifts. On tau^2-bench airline, retail, and telecom tasks, mean **Pass^4** rises from **0.42** to **0.62**, with the biggest gain on the most workflow-shaped domain, telecom (**0.19 -> 0.61**). The transfer across GPT-5.4, Claude Sonnet 4.6, and Gemini 2.5 Pro is also a useful sign that the state machine is doing real work instead of just leaning on one model's prompt habits.

### 5. **Orthogonal JEPA: Factorized Predictive States for Latent World Models**

**Verdict:** adjacent inspiration, not yet preserve-worthy.

Why it matters: This is one of the better latent-world-model papers in the batch because it attacks a real representational problem rather than just changing branding. Instead of making one predictive embedding carry everything, it factorizes target state into learned orthogonal components, predicts each with its own branch, then synthesizes the full latent state back together. The mechanism is clean: learned basis matrices, orthogonality constraints, factor-activity regularization, and online variance regularization. It stays just below the preserve bar because the current read gives a broad multi-domain demonstration across vision, transcriptomics, health records, control, and molecular dynamics, but not yet one especially brutal long-horizon case that forces the factorization to prove its necessity.

## Most relevant to cabbageland

**Most relevant today:** **Can Agent Memory Systems Track Evolving State?**

It gets unusually close to the real failure mode. The useful move is not "more memory" but explicit handling of supersession and dependency so the system can keep the state that is still live rather than merely the state that was once said. The rest of the digest rhymes with that taste. **Credit Without Ground Truth** separates causal contribution from correctness proxies. **DeltaML-Bench** separates real improvement from scoreboard gaming. **PolicyGuide** separates policy-compliant workflow state from one-off action filtering. **Orthogonal JEPA** separates predictive factors instead of making one latent soak up everything.

## Novelty / framing / baseline impact

**StateMem** matters because it turns state tracking into a separate benchmark axis rather than pretending recall scores already cover it.

**Credit Without Ground Truth** matters because it audits step credit against executed replay and forces training comparisons to control for dose rather than mystifying sparse credit signals.

**DeltaML-Bench** matters because it brings integrity verification and real repo heterogeneity into ML-agent evaluation instead of assuming a benchmark score is automatically a valid improvement.

**PolicyGuide** matters because it reframes policy compliance as a workflow-state problem, not merely a local action-guarding problem.

**Orthogonal JEPA** matters because it pushes latent world models toward explicit predictive factorization instead of monolithic target embeddings.

## One-paragraph takeaway

The August 21 lesson is that a system should be judged by whether it maintains and acts on the operative state, not by whether it stores a plausible proxy. StateMem keeps track of what is still active after revisions. Credit Without Ground Truth shows that fluent-looking credit signals do not track causal contribution. DeltaML-Bench shows that nominal improvements are not trustworthy without integrity checks inside messy real repositories. PolicyGuide shows that policy compliance requires a persistent workflow graph, not just local vetoes. Orthogonal JEPA argues that a predictive latent should expose separable factors instead of collapsing them into one undifferentiated state vector. Same rule all day: if the mechanism does not preserve the state that actually matters, the headline result is partly fake.
