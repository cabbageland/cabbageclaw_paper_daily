# Daily Paper Digest - 2026-09-15

## Theme

Today is a controllability and modality-weight batch. The strongest papers ask whether an internal object actually has the causal role assigned to it. A video world model may contain the physically correct future without letting that future control generation. A one-step offline RL policy can keep multimodal action structure if value is used to allocate target mass rather than pull the actor directly. A brain-signal foundation model needs language-signal alignment and routed experts, not just a generic multimodal wrapper. A medical VLM can look competent while its report input suppresses image sensitivity. A latent action model can reconstruct future frames while failing to learn or use actions.

## Ranked papers

### 1. **A Chosen Future Can Still Be Rewritten: Causal Writability in Video Models**

**Verdict:** must read direct paper.

Why it matters: This is the cleanest world-model mechanism paper in the batch. It asks whether a physically correct future is missing from the model or merely not controlling the natural rollout. In controlled color-motion conflicts, the model may generate the shortcut future, but a compact activation edit predicted from target motion and boundary physical state can restore the motion-consistent future. Four coordinates retain nearly the full edit effect, and a donor-free controller succeeds on 85.9% of held-out writes. The important idea is causal writability: the correct variable can remain internally available while its route to output closes across depth. Training, more observed motion, and motion-first adaptation move that closure boundary.

### 2. **Learning Multimodal One-step Flow Policy via Value-weighted Optimal Transport**

**Verdict:** highly relevant direct paper.

Why it matters: OptiFlow is a useful offline RL mechanism because it separates value selection from actor extrapolation. Instead of directly maximizing critic estimates, it samples reference-policy and one-step-policy actions, gives high-value reference actions more marginal mass, and uses state-wise entropic optimal transport to assign one-step samples to geometrically compatible targets. This preserves multimodal action structure while keeping the deployed actor one-step. The strongest evidence is on OGBench manipulation and visual tasks: state-based OGBench average rises to 48.3 versus 45.6 for GFP and 39.0 for FQL, and visual OGBench average reaches 75.9 versus 65.4 for FQL. The caveat is added training complexity and sensitivity to reference/critic quality, but the design lesson is portable.

### 3. **A Language-Guided Multimodal Foundation Model for Zero-Shot and Multi-Task Brain Signal Analysis**

**Verdict:** highly relevant adjacent paper.

Why it matters: METIS is today's strongest neuro/clinical foundation-model candidate. It pretrains a signal-language model over more than 70,000 hours from over 11,000 subjects across 20 EEG/iEEG datasets, then evaluates zero-shot, few-shot, open-ended signal QA, and cross-dataset transfer. The useful modeling move is to make clinical brain-signal labels instruction-conditioned answer tokens, with a universal signal encoder and mixture-of-experts routing to manage modality and task heterogeneity. The headline zero-shot AUROC is 75.5%, above the 1%-shot supervised average, and few-shot/cross-dataset results show large margins over EEG-specific baselines. The clinical caveat is that this remains retrospective benchmark evidence, not deployment evidence, but the language-signal alignment idea is strong.

### 4. **ModaLens: Measuring Image Sensitivity in Report-Conditioned Medical VLMs**

**Verdict:** highly relevant direct diagnostic paper.

Why it matters: ModaLens is a sharp audit for silent modality failure. It holds the radiology report and question fixed, swaps only the image, and asks whether the answer changes. On 44,786 MIMIC-CXR paired trials, MedGemma-27B's generated answer changes on 4.26% of trials with the report and 20.94% without it under an explicit answer instruction. Continuous margins move the same way, and the direction replicates across other model families. The authors are careful: the labels are report-derived, so this measures image sensitivity, not visual correctness. The steal-worthy pattern is the audit itself: intervene on one modality, keep the rest fixed, and separate "the model was accurate" from "the model used the evidence it claimed to use."

### 5. **Reconstructing Is Not Acting: Action-Centric Latent Dynamics Modeling**

**Verdict:** highly relevant direct paper, with robotics-scope caution.

Why it matters: ACT-LAM is worth preserving because it names a real proxy failure: low future-frame reconstruction loss does not imply a useful latent action. The paper identifies two underconstraints: the inverse model can encode nuisance transition information, and the forward model can ignore the inferred action while reconstructing from state shortcuts. ACT-LAM answers with action-query extraction and evolving action-token conditioning. It reaches 49.04 aggregate VP2 success versus 41.44 for DiLA and 21.54 for AdaWorld, while using fewer FLOPs and less memory than DiLA. The caveat is that this is still a robotics/video benchmark paper, but the broader lesson is clean: reconstruction is not evidence of control-relevant state.

## Most relevant to cabbageland

**Most relevant today:** **A Chosen Future Can Still Be Rewritten: Causal Writability in Video Models**

It gives cabbageland a reusable distinction between readable internal information and causally usable internal information. That applies beyond video: world models, memory systems, state abstractions, tool traces, and agent plans can all contain a useful variable that no longer controls the actual output. The right question is not just "is the variable present?" but "can this variable still write the future?"

## Novelty / framing / baseline impact

**Causal Writability** matters because it reframes shortcut failures as controllability failures, not only missing-representation failures.

**OptiFlow** matters because it uses critic values to allocate transport mass while keeping actor training anchored to reference-policy support.

**METIS** matters because it treats brain-signal analysis as instruction-conditioned signal QA with routed modality/task capacity, not as a pile of task-specific EEG classifiers.

**ModaLens** matters because it separates report-derived accuracy from actual image sensitivity in medical VLMs.

**ACT-LAM** matters because it turns "reconstruction is not action understanding" into measurable extraction and utilization diagnostics.

## One-paragraph takeaway

The September 15 pattern is that evidence only counts if it has causal authority. A physical future can be represented but not writable. A critic can identify good actions but should not be trusted to pull a one-step actor off support. A brain-signal model needs semantic alignment inside the representation, not after a frozen embedding. A medical VLM can answer from text while barely moving with the image. A latent dynamics model can reconstruct pixels while wasting its action variable. Same rule across domains: audit whether the claimed carrier actually carries the decision.
