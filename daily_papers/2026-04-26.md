# Daily Digest — 2026-04-26

## Theme

Today’s useful cluster is explicit task management for long-horizon robot behavior. The strongest papers are not claiming that a bigger end-to-end policy will somehow absorb planning. They carve out visible structure for progress tracking, correction, and branch reuse.

## Short overview

Brave search was attempted first in this run, but discovery was blocked because the Brave Search API key is missing. So scouting fell back to direct arXiv API discovery plus primary-source inspection through arXiv abstract and HTML pages. I inspected the abstract and substantial HTML text for **Long-Horizon Manipulation via Trace-Conditioned VLA Planning**, **Hi-WM: Human-in-the-World-Model for Scalable Robot Post-Training**, and **VistaBot: View-Robust Robot Manipulation via Spatiotemporal-Aware View Synthesis**.

The strongest paper today is **Long-Horizon Manipulation via Trace-Conditioned VLA Planning**. The real move is not “use a manager.” It is the specific contract: predict a progress-aware remaining plan plus a lightweight 2D trace, then let a short-horizon executor repeatedly follow that explicit spatial prompt. That turns long-horizon control into a receding-horizon loop with visible memory rather than hidden persistence inside a monolithic action model.

**Hi-WM** is still highly relevant, even though it was already preserved yesterday. Its best idea is to treat failure states as reusable assets: roll out in a world model, intervene around failure, then rollback and branch multiple corrective continuations from the same state. That is a much more concrete use of a world model than just generating prettier imagined futures.

**VistaBot** is adjacent and somewhat mixed. The geometric-plus-diffusion fusion for viewpoint robustness is real engineering, and the view-generalization metric is useful pressure. But the paper is more about perception robustness than about explicit memory, planning, or controllable task structure. For this repo, it is relevant mostly as support infrastructure, not as a core mechanism paper.

## Ranked papers

### 1. **Long-Horizon Manipulation via Trace-Conditioned VLA Planning**

**Verdict:** highly relevant.

Why it matters: it gives long-horizon manipulation an explicit manager-executor interface with remaining-plan memory and a spatial trace prompt, instead of hoping long-horizon competence will emerge inside one reactive policy.

### 2. **Hi-WM: Human-in-the-World-Model for Scalable Robot Post-Training**

**Verdict:** highly relevant.

Why it matters: it turns a world model into a rollback-and-branch correction workspace around real failure states, which is exactly the kind of explicit reusable structure that world-model papers often claim but do not deliver.

### 3. **VistaBot: View-Robust Robot Manipulation via Spatiotemporal-Aware View Synthesis**

**Verdict:** useful but adjacent.

Why it matters: it attacks viewpoint brittleness with explicit geometry plus diffusion-based latent synthesis, but the main contribution sits closer to robust perception plumbing than to planning or structured control.

## Most relevant to cabbageland

**Most relevant today:** Long-Horizon Manipulation via Trace-Conditioned VLA Planning.

The steal-worthy part is the split between a progress-aware manager and a generic executor. The manager predicts what is done, what remains, and a 2D trace for where the next interaction should go. That is a cleaner interface than asking a single VLA to simultaneously remember task state, recover from drift, and emit low-level actions.

Hi-WM is the better paper if the question is how to reuse failure states for data collection and post-training. LoHo-Manip is the better paper if the question is how to make long-horizon execution legible at inference time.

## Novelty / framing / baseline impact

LoHo-Manip adds pressure on long-horizon VLA papers that hide all progress tracking inside the policy. If a system claims multi-step robustness, the obvious questions should now be: where is the explicit task-state representation, how is failure persistence handled, and what stable interface connects planner to executor?

Hi-WM adds pressure on world-model framing. A world model should do more than hallucinate futures or rank checkpoints. It should ideally create reusable intervention structure, especially around failure basins.

VistaBot adds evaluation pressure in a narrower sense. If a manipulation policy claims robustness, camera-view shift should be treated as a first-class stress test rather than an afterthought.

## One-paragraph takeaway

The useful lesson today is that robotics papers get more interesting when they stop pretending end-to-end mush will organize itself. LoHo-Manip makes progress state and near-term spatial intent explicit at inference time. Hi-WM makes failure states explicit and reusable during post-training. VistaBot is less central for this repo, but still reinforces that perception invariance should be built with structure rather than assumed. The strongest throughline is simple: separate roles, expose state, and make the control interface visible.
