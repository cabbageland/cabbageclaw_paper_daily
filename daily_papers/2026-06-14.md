I inspected full arXiv PDFs for **muVLA: On Recurrent Memory for Partially Observable Manipulation in VLA Models**, **Improving Robotic Generalist Policies via Flow Reversal Steering**, **Sparse2Act: Learning Action-Aligned Sparse 3D Representations for Cross-Domain Robot Manipulation**, **Mana: Dexterous Manipulation of Articulated Tools**, **DIRECT: When and Where Should You Allocate Test-Time Compute in Embodied Planners?**, **SERF: Spatiotemporal Environment and Robot Feature Map for Long-Horizon Mobile Manipulation**, and **MCR-Bionic Hand: Anatomical Structural Priors for Dexterous Manipulation**. muVLA and Sparse2Act are preserved today.

**muVLA** is the strongest direct hit. It adds a small bank of recurrent memory tokens to OpenVLA-OFT and deliberately avoids retrieval modules, compression heads, hierarchical memory, and auxiliary objectives. The payoff is a cleaner measurement: minimal recurrence lifts partially observable MIKASA-Robo training tasks sharply, transfers modestly to held-out tasks with matching memory semantics, and mostly fails when the memory semantics change. That limit is the value. The paper gives future VLA memory work a baseline and a warning: if a fancier memory system cannot beat tiny recurrent tokens under the same cadence and latency budget, it is probably ornament.

**Sparse2Act** is the best representation paper today. It pretrains sparse point-cloud encoders by masking 3D tokens and predicting one-step task-space end-effector actions, then transfers only the encoder initialization into downstream policies. The ablations are the useful part: action-only and reconstruction-only help, but masked action alignment helps far more, and the gain persists with simplified downstream decoders. The design lesson is portable: use robot action to organize geometry around control, then let the downstream policy choose its own action parameterization.

**DIRECT** is adjacent but practically important. It treats the high-level embodied planner as a routed variable across reasoning depth, model size, and memory history. The paper's best claim is not "bigger reasoning helps"; it is the opposite: compute axes help on different task types and can hurt or waste latency elsewhere. A lightweight multimodal router recovers much of the expensive planner's success at lower cost in simulation and Franka DROID experiments. This is more systems and deployment than core representation, so I did not preserve a separate note today, but the framing is worth stealing.

**Flow Reversal Steering** is good policy-improvement material. It reverses a flow-matching VLA from coarse reference actions into latent noise, then denoises back into in-distribution actions that follow the rough semantic direction. It is especially useful for turning human or VLM guidance into noise-space BC or RL warm starts. I am not preserving it today because it is a steering wrapper over a behavioral prior rather than a stronger state, memory, or representation interface.

**SERF** is a strong explicit-memory mobile-manipulation paper, but with simulation caveats. It builds a spatiotemporal feature map of environment and robot neural points, updates environment points by object-level SE(3) tracking and robot points by forward kinematics, then conditions a VLA on map tokens. The idea is aligned with cabbageland: persistent spatial memory should be an input, not hidden in image history. The limitation is also clear: prior map features, privileged simulator instance labels, rigid-object updates, and no real-world mobile-manipulation validation yet.

**Mana** and **MCR-Bionic Hand** are useful physical-structure papers. Mana turns articulated tool manipulation into an animation-like data pipeline: human marks functional affordances, the system samples grasp keyframes, plans geometric phases, and uses RL only for short contact-rich transitions before training a point-cloud diffusion policy for zero-shot sim-to-real. MCR-Bionic is more hardware/anatomy than learning: it argues that wrist-finger tenodesis, extensor hoods, and intrinsic pathways are physical computation, not mere biomimetic decoration. Both are adjacent inspiration for "structure does work," but neither displaces today's two preserved representation/memory papers.

### 1. **muVLA: On Recurrent Memory for Partially Observable Manipulation in VLA Models**

**Verdict:** highly relevant, and the most relevant paper today.

Why it matters: it isolates recurrent memory as the only major treatment inside a pretrained VLA, showing both the real gains and the semantic-transfer limits of minimal latent recurrence.

### 2. **Sparse2Act: Learning Action-Aligned Sparse 3D Representations for Cross-Domain Robot Manipulation**

**Verdict:** highly relevant.

Why it matters: it uses task-space robot actions as geometric supervision for sparse 3D encoder pretraining, creating a reusable representation shaped around controllable workspace motion.

### 3. **DIRECT: When and Where Should You Allocate Test-Time Compute in Embodied Planners?**

**Verdict:** adjacent inspiration.

Why it matters: it makes test-time compute a routed interface with task-contingent value, instead of treating chain-of-thought, bigger models, or longer memory as uniformly good.

## Most relevant to cabbageland

**Most relevant today:** muVLA.

The steal-worthy idea is the controlled memory baseline. VLA memory papers should not get to hide behind a bundle of recurrence, retrieval, compression, scratchpads, and auxiliary losses. First ask: what happens if the same backbone gets only a few recurrent tokens, temporal training order, an action-copy guard, and a sane update cadence? muVLA says that buys a lot on trained partial-observability structures, a little on matched variants, and not much on genuinely new memory semantics.

Sparse2Act adds the representation companion. If the system has a metric 3D observation, action should supervise the representation before the policy head starts learning task behavior. Geometry is not merely something to reconstruct; it is a workspace for possible motion.

DIRECT adds the deployment companion. Memory, thinking, and model size are not moral virtues. They are budgeted resources. Route them when the task asks for them, and do not pay for them when the scene is simple.

## Novelty / framing / baseline impact

**muVLA** raises the baseline for VLA memory claims. Any new memory architecture should compare against minimal recurrent tokens under matched inference cadence and should report semantic-shift splits, not only average held-out task success.

**Sparse2Act** raises the baseline for sparse 3D representation learning. Reconstruction and dynamics pretraining are not enough when the claimed use is manipulation; action-aligned geometry should be in the comparison set.

**DIRECT** sharpens test-time compute framing. It is not enough to say chain-of-thought, larger planners, or longer memory improve average success. A robot planner needs a success-cost frontier and a routing policy.

**SERF** is useful framing for persistent spatial memory, but the privileged-map caveats matter. It supports the argument that VLA policies need explicit spatial state, while also reminding us that map construction assumptions can dominate the comparison.

## One-paragraph takeaway

The best paper today is **muVLA** because it gives VLA memory a controlled lower bound: tiny recurrent tokens can be powerful, but they do not magically generalize to new memory semantics. **Sparse2Act** is the representation note to keep because it uses robot action to shape sparse 3D geometry around control before downstream policy training. **DIRECT** is the adjacent systems lesson: expensive reasoning, bigger planners, and longer memory should be routed by task demand. The common thread is that useful long-horizon systems need small explicit interfaces with honest budgets, not bigger hidden mush.
