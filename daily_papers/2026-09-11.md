# Daily Paper Digest - 2026-09-11

## Theme

Today's best papers are about making generative systems read the right state carrier. A frozen video world model can be controlled by camera- and time-labelled visual evidence instead of retraining. A code world model can recursively hand subworlds their own executable solve. A diffusion or flow model can spend schedule time where its predictor is less risky. A video distillation student can keep diversity only if uncertainty survives the first autoregressive cache. A medical shape model can pair an anatomy prior with a differentiable ultrasound physics proxy.

## Ranked papers

### 1. **World in World: Explore the World with World Models**

**Verdict:** must read direct paper.

Why it matters: World in World is a clean control-interface paper for frozen causal video world models. Instead of fine-tuning a separate controller for each evidence type, it converts source-video observations, target-view projections, rendered geometry, and retrieved generated history into camera- and time-labelled clean visual states, then lets a frozen LingBot-World 2.0 causal-fast checkpoint read them through native self-attention. The useful mechanisms are correspondence-guided attention routing, which pushes generation queries toward geometrically matched source tokens, and evidence-wise attention CFG, which adjusts each auxiliary evidence channel inside the same denoising pass. On camera-controlled video rerendering, it reports the best overall VBench score, lowest rotation error, best PSNR/SSIM, and near-best LPIPS against ReCamMaster, TrajectoryCrafter, WorldForge, InSpatio-World, UniWorld-View, and CameraAnything. The caveat is that this is still evidence orchestration around a strong frozen model; it does not make the underlying model physically grounded or globally state-consistent by itself.

### 2. **Recursive Code World Models: Building Complex Worlds through Recursive Scene Programs**

**Verdict:** highly relevant direct paper.

Why it matters: RCWM has the strongest representational move in the batch. It treats image-to-3D reconstruction as recursive executable world construction rather than one flat code dump. The representation is a Recursive Scene Program: scene code with explicit child references, editable parameters, shared dependencies, and a solver that follows the same global-local-global loop at each node. A frozen vision-language coding agent establishes the whole, delegates unresolved components to child solver calls with matched reference/camera crops, then revisits the assembled parent to fix composition, boundaries, and spatial relations. On five whole-scene references and five local crops, RCWM obtains the highest PSNR and lowest LPIPS on every reference, and the ablation suggests recursive free-depth solves can improve local detail and whole-scene fidelity. The red flag is scale: the experiments are small, single-run, and use expensive agentic reconstruction rather than a robust learned pipeline.

### 3. **Model-Aware Schedules Improve Generation via Fiberwise Optimal Transport**

**Verdict:** highly relevant direct paper.

Why it matters: This is a diffusion/flow paper worth preserving because it turns schedule choice into a model-aware allocation problem rather than another hand-tuned noise curve. At a fixed state along an affine probability path, the compatible signal/noise decompositions form a fiber. The paper defines fiberwise prediction risk as optimal-transport cost between true and predictor-induced decompositions inside that fiber, estimates the risk profile from an early baseline checkpoint, and combines it with coefficient-path kinetic action to get a closed-form traversal-time allocation. The evidence is broad: on CIFAR-10 DDPM, DPM++3M at 16 NFE improves FID from 9.64 to 8.06, and on CIFAR-10 flow matching, midpoint 16 NFE improves FID from 7.62 to 4.68, a 38.6% relative reduction. The most interesting claim is the normalized risk-profile alignment across independently trained settings, which hints at a reusable schedule template. The caveat is that this is still schedule-time shaping on fixed curves; it does not solve architecture, data, or semantic-control limits.

### 4. **Uncertainty DMD: Restoring Diversity in Few-Step Autoregressive Video Distillation**

**Verdict:** highly relevant direct paper.

Why it matters: Uncertainty DMD diagnoses a real failure mode in efficient video generation. DMD is mode-seeking, so an autoregressive video student can map different noise samples to nearly identical first chunks; because the AR cache is deterministic, that collapsed first state then constrains every later chunk. The paper backs this with variance decomposition, cache transplantation, and teacher-versus-student sampler swaps, then fixes the state carrier directly: perturb the first-chunk timestep and stochastically write perturbed chunks into the historical cache, during both training and inference. On Causal Forcing, the method improves TE-CLIP from 19.8 to 22.1 and VENDI-DINO from 3.6 to 4.7 while keeping VBench quality comparable. On Self Forcing, it improves TE-CLIP from 16.4 to 19.5 and dynamic degree from 25.1 to 42.4. The caveat is that the paper mainly measures diversity and video-quality proxies; restored variation is not the same as controllable semantics.

### 5. **UBone3D: Physics-Rectified Conditional Flow Matching for Anatomical 3D Shape Completion from Ultrasound**

**Verdict:** highly relevant adjacent paper.

Why it matters: UBone3D is the medical/generative paper that cleared the guardrail because it has a real mechanism. It uses a CT-trained conditional flow-matching anatomy prior, BoneFM, then rectifies inference with USimNet, a differentiable proxy for ultrasound formation artifacts such as thickening, streaking, attenuation, and dropout. The important design choice is decoupling anatomical plausibility from physics consistency: BoneFM supplies the clean vertebra prior, while USimNet supplies observation-consistency gradients late in the flow trajectory. The in-vivo and simulated evidence is not perfect, but it is stronger than a pure benchmark claim: the full physics simulation aligns best with in-vivo point clouds, UBone3D is stable across CD/EMD/F-score tradeoffs, and the USimNet ablation improves CD/EMD/F1 from 49.196/96.673/0.064 without USimNet to 28.161/74.298/0.079 with the full proxy. The limitation is also clear: real in-vivo outputs still need improvement and the physics proxy is learned from simulation.

## Most relevant to cabbageland

**Most relevant today:** **World in World: Explore the World with World Models**

The transferable lesson is that a frozen world model can be extended by making the evidence look like a native state carrier and regulating how the model reads it. World in World does not pretend control is a prompt. It labels evidence with camera, time, spatial support, and availability; routes attention through geometric correspondences; and tunes each evidence source separately inside the denoising computation.

## Novelty / framing / baseline impact

**World in World** matters because it reframes world-model control as evidence construction and attention routing rather than task-specific retraining.

**Recursive Code World Models** matters because it turns executable scene code into a recursive handoff object, not a single flat output.

**Model-Aware Schedules** matters because it connects diffusion/flow schedule time to predictor-specific decomposition risk.

**Uncertainty DMD** matters because it locates video-distillation diversity collapse in the first autoregressive cache, then perturbs the state variables that carry the collapse.

**UBone3D** matters because it separates anatomy priors from ultrasound physics consistency and couples them only at inference.

## One-paragraph takeaway

The September 11 lesson is that generation improves when the system makes its state carrier explicit. World in World gives a frozen video model labelled visual evidence to read. RCWM gives local scene parts their own executable recursive solve before recomposition. Model-Aware Schedules turns schedule time into a risk allocation. Uncertainty DMD protects stochasticity where the AR cache begins. UBone3D lets anatomy and physics act as separate forces on the same flow trajectory. Different domains, same pattern: preserve the thing that has to survive the handoff.
