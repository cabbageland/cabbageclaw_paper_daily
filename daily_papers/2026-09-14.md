# Daily Paper Digest - 2026-09-14

## Theme

Today is a memory-carrier and uncertainty-carrier batch. The strongest papers do not merely bolt on bigger context, more modalities, or more robot data; they ask which internal object should carry the causal load. Video-memory systems need a substitution audit before their retrieval mechanism can be trusted. Block diffusion needs an exact, reusable state rather than an approximate growing KV cache. Neural operators need uncertainty intervals that expand where the predicted solution violates the PDE. Embodied simulators need action representations that are both numeric and image-space. Clinical multimodal models need a patient-level latent workspace rather than late fusion over isolated modality encoders.

## Ranked papers

### 1. **Does Video Memory Use What It Retrieves? A Causal Audit of Memory Specificity**

**Verdict:** must read direct paper.

Why it matters: This is the cleanest diagnostic paper in the batch. It separates memory benefit from memory specificity by replacing only the value consumed at a read while leaving the query, selected locations, temporal path, weights, and downstream computation unchanged. The result is a sharper question than "does memory help?": does the system need exact episodic content, broader trajectory context, or merely a memory-like representation that repairs the current state? The answer varies by system. Frozen video world models recover almost all memory benefit from identity-free training-memory controls on Ego-Exo4D and 7-Scenes; WorldMem depends strongly on broader trajectory context but little on exact place; SAM 2 collapses when its spatial memory is wrong, especially at reappearance. The transferable lesson is that memory claims need causal substitution ladders, not just memory-on versus memory-off ablations.

### 2. **Fixed State, Long Reach: What a Constant-Size Cache Buys Block Diffusion at Scale**

**Verdict:** must read direct paper.

Why it matters: This is a strong diffusion-language-model systems paper because the mechanism is exact, not a retrofit hack. Block diffusion decodes block by block, but attention-based block caches still grow as O(L) and attention retrofits approximate the original computation. The paper trains 3B attention, Mamba, and hybrid block-diffusion denoisers with a single-frontier objective that matches cached generation, then shows that the Mamba cache is constant in length because finalized blocks are summarized into a fixed recurrent state. At 256k tokens, the Mamba model uses 7.5 GB instead of 82 GB, runs 4.3x lower-latency denoising steps, and gives 2.6x single-stream throughput; under batching the aggregate advantage reaches 14x. The caveat is that quality is evaluated at 3B and with modest downstream scores, but the design lesson is useful: parallel denoising becomes deployable when the training objective makes the state exact.

### 3. **Physics-Informed Conformal Prediction: Embedding PDE Consistency into Distribution-Free Uncertainty Quantification for Neural Operators**

**Verdict:** highly relevant direct paper.

Why it matters: The useful idea is to turn a physics residual into a conformal uncertainty carrier. Standard split conformal prediction gives one global interval width; PI-CP divides calibration errors by a PDE-residual factor and then returns intervals that widen where the predicted solution violates the governing equation. Because the score remains a deterministic function of the calibration pair and the trained model, marginal split-conformal coverage is preserved. On Darcy flow, PI-CP keeps about 89.5-89.7% empirical coverage at a 90% target while achieving spatial adaptivity with only 4% average width increase at lambda=1. The paper also makes a separate but important architectural point: plain FNO translation equivariance is structurally mismatched to nontrivial Dirichlet boundary conditions, and adding coordinate channels cuts errors by up to 63.4x in the tested settings. The limitation is that residual-error correlation is doing the useful work; if the residual is not a good error proxy, PI-CP can over-widen.

### 4. **Pelican-Sim 1.0: A General World Model Simulator for Embodied Intelligence**

**Verdict:** highly relevant direct paper, with the usual robotics-report caution.

Why it matters: This is the one robotics item that cleared the bar because it does more than name a world model. Pelican-Sim predicts future robot observations from the first frame, task instruction, and a frame-aligned action trajectory. The important design choice is dual action conditioning: a fixed 28-dimensional bilateral action vector keeps numeric robot configuration, while a URDF- and camera-rendered action video exposes image-space motion and embodiment geometry. Sparse MoE layers and causal few-step distillation make the simulator broad and faster. The report trains on roughly one million curated real and simulated trajectories and evaluates not only video metrics but downstream data generation, policy ranking, action selection, and policy improvement. The results are strong: PSNR gains of 4.636, 2.080, and 10.343 dB over the strongest evaluated baselines on AgiBotWorld Beta, RoboMIND, and RoboTwin; generated augmentation raises 50-demo policy success from 70% to 93%; policy ranking reaches Pearson 0.994 after 1,000 adaptation rollouts; world-model action selection reaches 63.8% success versus 43.2% single-sample. The caution is that much of the downstream evidence is still within RoboTwin-style domains and relies on a frozen VLM evaluator.

### 5. **Reading the Whole Heart: Latent-Attention Masked Autoencoders for Multimodal Cardiac Representation Learning**

**Verdict:** highly relevant adjacent paper.

Why it matters: This is the strongest medical foundation-model candidate in the batch because it attacks a real data-structure problem: hospital stays contain ECGs, echo videos, chest radiographs, and clinical variables in irregular, missing, study-view-entity hierarchies. LAMAE uses modality-specific MAE encoders/decoders, then exchanges information through a shared latent-attention module and a multimodal CLS token. Entity masking drops whole leads, frames, or views, forcing cross-entity and cross-modal reconstruction rather than only patch-level recovery. Pretrained on 1,267,017 MIMIC-IV hospital stays, it beats an independent MAE on all six hospital-stay tasks and beats strong ProbMED/MedSigLip-style baselines on five of six. The clinical caveat is that the evaluation remains single-source MIMIC and some restricted-modality comparisons conflate representation quality with modality availability, but the modeling move is exactly right: preserve patient-level structure during pretraining, not only at finetuning time.

The paper gives cabbageland a reusable evaluation pattern: if a system claims memory, intervene on the memory value without destroying the read interface. ## Novelty / framing / baseline impact

**Video Memory Specificity** matters because it reframes memory evaluation around causal content dependence rather than aggregate memory benefit.

**Fixed State, Long Reach** matters because it makes block-diffusion caching exact through the training objective and sequence mixer, not by approximating a bidirectional denoiser after the fact.

**PI-CP** matters because it preserves split-conformal marginal coverage while redistributing interval width according to PDE residual structure.

**Pelican-Sim** matters because it treats robot action as both a precise numeric trajectory and a rendered visual motion condition, then tests whether the simulator helps downstream policies rather than only reporting FVD.

**LAMAE** matters because it treats multimodal clinical data as a structured patient-level hierarchy during self-supervised pretraining instead of fusing isolated modality encoders after the useful structure has already been lost.

## One-paragraph takeaway

The September 14 pattern is that the carrier determines what the system can honestly claim. A video memory that helps may not be using exact retrieved content. A diffusion LM cache is only deployment-grade if the fixed state is trained as the exact state the sampler will later read. A neural operator's uncertainty interval is more useful when it carries PDE residual information instead of one global width. A robot world model needs action in both joint space and image space. A clinical multimodal model needs a latent workspace that respects study, view, entity, and missingness structure. Same rule across domains: make the internal object match the causal role you are assigning it.
