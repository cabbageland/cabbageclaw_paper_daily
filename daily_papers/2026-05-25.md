# Daily Paper Digest — 2026-05-25

## Theme

Today’s useful pattern is **explicit long-horizon state that stays decision-facing instead of decorative**. The strongest direct paper is **Point Tracking Improves World Action Models** because it replaces mushy pixel-only latent dynamics with an explicit point-track state that is actually used for robot control under occlusion and off-screen motion. **PathNavigate** is the best medical / agentic pick because it turns pathology VQA into a real search problem with slide-level surprise memory instead of pretending a frozen VLM can absorb a gigapixel slide in one shot. **HorizonStream** is the strongest adjacent systems paper because it treats long streaming 3D reconstruction as a memory-kernel design problem rather than a bigger-context problem.

## Short overview

Brave Search was unavailable in this environment because no Brave Search tool is configured for this run. AlphaXiv was also not used as a live discovery surface here, so discovery fell back to recent arXiv inspection plus direct arXiv HTML/PDF reads.

I inspected the full text for **Point Tracking Improves World Action Models**, **PathNavigate: A Training-Free Pathology Agent with Surprise-Guided Scan and Shared Slide Memory for Whole-Slide Image VQA**, and **HorizonStream: Long-Horizon Attention for Streaming 3D Reconstruction** through arXiv HTML and PDF text extraction. Confidence is good on mechanism, evaluation setup, and headline results, and weaker on appendix-level implementation details I did not audit line by line.

**Point Tracking Improves World Action Models** is the most relevant paper today. The central move is simple and strong: instead of letting a world-action model operate only on image latents, it jointly predicts future frames, point tracks, and visibility, then conditions action selection on both latent and explicit motion state. The paper calls the resulting controller JOPAT. This matters because it gives the policy a representation that can carry contact-induced motion, temporary occlusion, and off-screen displacement more legibly than pixel latents alone. The main caveat is that this is still a fairly engineered hybrid, not a clean general-purpose world model abstraction.

**PathNavigate** is the best non-robotics paper in the batch, and I’m glad it exists. It frames whole-slide pathology VQA as extreme-context evidence search, builds a low-magnification surprise map before question-conditioned reranking, then performs high-magnification readout only on selected regions. That is a much better decomposition than patch dumping or question-first guessing. It is still a frozen-stack agent rather than a learned memory system, but the structure does real work and the memory is tied to concrete evidence selection rather than branding.

**HorizonStream** is adjacent but worth preserving. It introduces Geometric Linear Attention, a recurrent O(1) geometric state with learned channel-wise retention, so evidence can decay smoothly across very long monocular sequences instead of being hard-reset or shoved into a contaminated KV cache. The paper’s value is not just benchmark placement. It gives a cleaner explanation for why streaming 3D systems break on long horizons and shows that memory shape matters as much as nominal context length.

I also inspected **SkillOpt** and **MemAudit** enough to triage them. SkillOpt has the right keywords but currently looks more like packaging around agent-skill optimization than a deep mechanism paper. MemAudit is directionally interesting for agent-memory security, but today’s preserved set felt stronger and more transferable.

## Most relevant to cabbageland

**Most relevant today:** Point Tracking Improves World Action Models.

What I like here is that the explicit structure is not cosmetic. The model does not merely add a side head for tracks and keep acting from the same opaque state. It uses joint latent-plus-track prediction and then conditions action generation on that combined representation, with visibility modeling to handle when points disappear. That means the explicit motion state is in the control loop rather than just in the paper’s diagrams.

This is exactly the kind of paper that helps pressure-test broader world-model rhetoric. If the task depends on object displacement, contact, or temporary observability loss, then a world model that only compresses appearance may simply be exposing the wrong state to the policy. I would not overclaim generality, but as a concrete demonstration that explicit motion state can improve policy robustness, it is strong.

## Novelty / framing / baseline impact

**Point Tracking Improves World Action Models** sharpens a useful baseline question for robot world models: is the learned state actually good at carrying object motion and visibility through interaction, or is the policy mostly leaning on short-horizon appearance reconstruction? After this paper, pixel-latent-only baselines look less satisfying when the claimed target is robust long-horizon manipulation.

**PathNavigate** improves the framing of pathology agents. Instead of treating whole-slide reasoning as prompt engineering over a frozen perceptor, it makes search policy, memory, and answer-time evidence budget first-class system components. That is a stronger decomposition and a better baseline target for future pathology-agent papers.

**HorizonStream** makes a different but related point. Long-sequence competence is not just “more context.” The actual retention kernel matters. Hard refreshes and naive cache carryover now look like crude memory policies rather than neutral engineering choices.

## One-paragraph takeaway

The best paper today is **Point Tracking Improves World Action Models** because it shows that explicit point-track state can improve world-model-based robot control where appearance-only latents start to blur away the motion structure that action really needs. **PathNavigate** is the strongest medical / agentic paper because it treats whole-slide pathology VQA as bounded evidence search with shared slide memory instead of giant-context prompting theater. **HorizonStream** is the best adjacent paper because it turns long-horizon streaming reconstruction into a principled retention problem with constant-memory recurrent state. The shared lesson is that persistent internal structure matters only when it stays tied to the actual decision interface, whether that interface is robot action, pathology evidence selection, or online geometric reconstruction.
