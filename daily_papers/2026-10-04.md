## Ranked papers

### 1. **World Observer: Joint Actor-Observer Generation for Persistent World Modeling**

**Verdict:** must read direct world-model paper.

Why it matters: World Observer gives a clean architectural answer to a persistent world-model failure. Actor-centric video models lose objects once they leave the camera, then hallucinate, freeze, or replace them when they re-enter. This paper jointly generates an actor view and one or more panoramic observer streams with shared DiT attention, synchronized temporal positions, separate actor/observer prompts, panorama grounding, and an Observer Sink of high-resolution perspective references. The observer is not just static context; it is a generated stream where off-screen state keeps evolving. The evaluation is also useful: OOV-F and OOV-D lift segmented objects into 3D and measure whether out-of-view motion continues correctly. The limitation is that the method assumes panoramic conditioning, but the central lesson is strong: persistent state should be represented where the generator can attend to it.

### 2. **MIRTO: a registration-gated, multiverse-tested evaluation protocol for unsupervised anomaly segmentation in brain MRI**

**Verdict:** highly relevant direct evaluation paper.

Why it matters: MIRTO is not a new model; it is a good antidote to sloppy medical AI leaderboards. The protocol checks registration before scoring, sets thresholds on validation data rather than the test cohort, reports realised false-positive burden, sweeps 15,552 defensible evaluation pipelines, and attaches paired bootstrap intervals with multiplicity control. The concrete result is nasty in the right way: an axis-order mismatch drops a diffusion model's voxel AUROC from 0.873 to 0.583 while slice-level AUROC barely moves, meaning a plausible table can hide a broken spatial comparison. It also shows Dice advantages disappearing at equal realised false-positive burden, and lesion sensitivity being dominated by lesion definition and hit criterion. The cabbageland lesson is that evaluation choices are part of the mechanism, not a footnote.

### 3. **Causal Memory Policy: Making Memory Utility Identifiable by Intervening on Retrieval**

**Verdict:** highly relevant direct memory-mechanism paper.

Why it matters: CMP names a precise failure in memory-augmented LLMs: if a memory is never retrieved, store-level interventions cannot estimate its utility because both observed outcomes are identical. The paper treats this as a retrieval-level positivity violation and fixes it by intervening on retrieval itself, reserving context slots for memories sampled with known propensities. A self-normalized inverse-propensity estimator then measures per-query memory utility. Empirically, retrieval support fails for 54% of required LongMemEval memories and 67% on LoCoMo, while CMP improves required/non-required discrimination from 0.542 to 0.664 and halves gold loss in one LongMemEval eviction setting. The caveat is central: identified per-query utility still does not solve retention, because a deployed retention policy needs future query distribution information.

### 4. **GeoLatent: Geometry-Guided Latent Structuring with Routed Optimization for 3D Reasoning**

**Verdict:** highly relevant direct 3D reasoning representation paper.

Why it matters: GeoLatent is useful because it does not merely say "latent geometry"; it tries to prove the geometry latents are differentiated and used. The method replaces a collapsing coverage-style geometry objective with Common-Residual Geometry Alignment, separating shared teacher geometry from residual components, then uses a routed curriculum that temporarily forces answer learning through the decomposed latents before restoring full attention. CR-GEO raises geometry effective rank from 1.00 to 3.87, latent readout blocking collapses direction accuracy from 89.1% to 25.8% on a controlled set, and the final model improves SPAR-Bench and SPBench over reported baselines. The limitation is that the evidence remains benchmark-local and partly inherited from GeoAnchor's setup, but the representation audit is the valuable part.

### 5. **Decision Titan: Test-Time Training for Long-Term Memory in Offline Reinforcement Learning**

**Verdict:** useful direct RL/control memory paper.

Why it matters: Decision Titan is a compact study of whether Titans-style test-time-training memory can help Decision Transformers with long dependencies. The model inserts a Titans Memory-as-a-Layer block into a Decision Transformer and trains on full trajectories so the learned fast-weight memory state rolls through chunks. The X-Maze environment isolates sequential memory: the agent receives a sequence of instructions, waits, and later repeats them. DTi learns dependencies at least 20x longer than its context window and extrapolates to about 1.7x the training waiting length, but the read is refreshingly non-magical. It needs recall cues the memory can associate with earlier keys, benefits from more memory heads mostly because they create more chances for a useful propagation path, and still falls apart from catastrophic forgetting over longer horizons.

## Most relevant to cabbageland

**Most relevant today:** **World Observer: Joint Actor-Observer Generation for Persistent World Modeling**.

It matters because cabbageland keeps circling explicit state in world models. World Observer turns "remember off-screen state" into an architectural split between acting and observing, then evaluates whether the off-screen state actually evolves.

## Novelty / framing / baseline impact

**World Observer** matters because it makes out-of-view state a generated observer stream rather than relying on actor-view context or static panoramas.

**MIRTO** matters because it treats registration, threshold transfer, and metric choice as first-class experimental variables.

**Causal Memory Policy** matters because it distinguishes retrievability from usefulness and shows why memory utility cannot be estimated for memories the retriever never exposes.

**GeoLatent** matters because it audits whether geometry latents are differentiated and causally used by answer learning.

**Decision Titan** matters because it tests TTT memory in offline RL and exposes the conditions under which parameter memory actually persists.

## One-paragraph takeaway

The October 4 pattern is that hidden state only counts if the system is forced to expose and test it. A world model needs an observer stream if off-screen objects are meant to keep evolving. A medical segmentation benchmark needs registration checks and threshold accounting if leaderboard numbers are meant to mean anything. A memory system needs randomized retrieval exposure if unretrieved memories are supposed to have measurable utility. A 3D reasoning model needs evidence that its geometry latents carry geometry and route answers. A long-memory RL model needs to show how fast weights persist, decay, and fail. The shared rule is simple: do not accept hidden state as a story; make it an instrumented object.
