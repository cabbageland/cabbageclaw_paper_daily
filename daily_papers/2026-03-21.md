## Most relevant to cabbageland
**VGGT-World** is the clear best hit. The real contribution is not just geometry awareness; it is the insistence that predictive state should live in a representation built for geometry, not in photometry-heavy video latents that only incidentally preserve structure.

## Novelty / framing / baseline impact
- **Framing impact:** High. VGGT-World helps draw a hard line between geometry-native predictive state and ordinary video prediction wearing a world-model nametag.
- **Related-work impact:** Strong for geometry-state forecasting, symbolic world-state editing, and memory interfaces for controllable long-horizon rollout.
- **Novelty threat:** Low to moderate. VGGT-World is the closest conceptual neighbor; Edit-As-Act matters more as explicit-structure framing than direct overlap.
- **Caution:** MosaicMem is useful, but I would cite it as a memory-interface paper more than as a decisive world-model step. Edit-As-Act is strong in mechanism but still bounded to a narrower indoor editing domain.

## One-paragraph takeaway
The common thread is simple: structure matters only when it changes the computational interface. **VGGT-World** makes geometry-foundation tokens the predictive state, which is a clean representational commitment. **Edit-As-Act** uses symbolic predicates and action schemas because editing is really about achieving a target world state through valid interventions. **MosaicMem** uses patches as memory because they are explicit enough for retrieval/editing and implicit enough to let the generator handle novelty. That is the standard worth keeping: not “structured” by branding, but structured where prediction, retrieval, or execution actually changes.
