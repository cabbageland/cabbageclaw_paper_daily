# Daily Paper Digest - 2026-06-07

## Theme

Today's useful pattern is **memory and world models are becoming selection-and-state interfaces, not just bigger context**. **PatchWorld** is the most directly relevant paper because it turns logged text-agent trajectories into executable belief-state programs that can be replayed, patched, and used for planning. **Worth Remembering** is the best embodied-memory paper because it gives memory formation a causal, unsupervised write gate based on surprise in a predictive video-feature space. **LongSpace** is the strongest benchmark/method note because it asks whether video MLLMs can preserve spatial evidence across long room-tour sequences rather than merely accept more frames.

A Layered Framework for Knowledge Infusion in Multimodal Iterative Generative Models**. PatchWorld, Worth Remembering, and LongSpace are preserved today. HyperVis and LatentSkill are useful citation material, but I am not preserving full notes for them in this run. The knowledge-infusion paper is a decent taxonomy, but not close enough to the repo's embodied/world-model center to spend a note slot today.

**PatchWorld** is the strongest direct hit. It induces Python world models with explicit symbolic belief state, transition rules, correction logic, and readout logic from offline text-agent trajectories. Prediction failures become typed counterexamples for code repair. The most important result is not just better text prediction; it is the observed frontier between observation fidelity and planning utility. The residual-memory variant predicts surface text better, while the simpler symbolic variant gives better live one-step planning utility.

**Worth Remembering** is the cleanest embodied-memory mechanism. It computes surprise in V-JEPA-2 latent space with a causal sliding-window Gaussian surrogate, stores only thresholded local maxima as visual episodes, and augments a 4D scene-graph memory. On OC-NaVQA, the surprise-gated memory improves question accuracy over DAAAM from 0.711 to 0.796 while storing about 1.7% of frames. The caveat is that the causal predictive model is still a simple Gaussian over embeddings, not a rich action-conditioned video world model.

**LongSpace** is worth keeping as benchmark and architecture pressure. LongSpace-Bench contains 445 room-tour videos, about 159 hours, and 4,073 QA pairs covering scene perception, spatial relations, and spatial memory. LongSpace combines 3D spatial-token injection with layer-aware hierarchical KV memory. The key result is that long-memory inference reaches 49.2 on LongSpace-Bench versus 36.1 for uniform 32-frame sampling and 37.7 for recent-window inference, with gains growing on longer videos.

**HyperVis** is a good citation for continuous relational structure. Its strongest point is that textual scene-graph triplets can hurt VLM accuracy, while continuous hyperbolic relation tokens improve compositional scoring. I am not preserving it today because it is static-image VQA/compositional scoring rather than embodied memory, planning, or world modeling.

**LatentSkill** is useful adjacent agent-systems material. Converting textual skills into LoRA adapters is a real interface move, but the current evidence is mainly ALFWorld and Search-QA efficiency/composition. It belongs in a future agent-skill synthesis more than today's paper daily note set.

## Most relevant to cabbageland

**Most relevant today:** PatchWorld.

The steal-worthy idea is the repairable world-model substrate. PatchWorld treats an offline trajectory log as evidence for a compact executable hypothesis about hidden state and transition dynamics. The model is not a prompt trace, not a fine-tuned black box, and not a lookup table pretending to be structure. It is a Python module with a fixed interface: parse observation, correct belief, predict belief, read out observation, and expose action forms. That makes failure analysis concrete enough for counterexample-guided repair.

Worth Remembering is almost as important for embodied memory. The useful move is not "memory helps." The useful move is deciding what deserves a high-resolution episodic record under capacity limits. Surprise is an imperfect proxy for future utility, but it is much less lazy than keeping every frame or relying on a downstream retriever to rescue a bad write policy.

LongSpace matters because it pressures long-video and embodied-memory systems to report whether memory survives distance, viewpoint changes, route dependencies, and state changes. Bigger context windows are not the same as spatial memory. LongSpace-Bench is useful precisely because it makes that distinction harder to blur.

## Novelty / framing / baseline impact

**PatchWorld** raises the baseline bar for "world model for agents" papers. If a paper claims planning utility, future comparisons should ask whether the world model preserves decision-relevant contrast, not only whether it reconstructs surface observations. PatchWorld's fidelity-versus-utility result is valuable because it shows those goals can diverge.

**Worth Remembering** sharpens memory-write baselines. Uniform and random episodic memory are not enough if a paper claims selective long-term robot memory. The write policy should be explicit, capacity-aware, causal if the deployment is causal, and tested against the same memory budget.

**LongSpace** raises the evaluation bar for video spatial memory. A model that processes more frames has not necessarily built memory. The benchmark pressure should be: can it retrieve evidence observed much earlier, maintain route and state information, and avoid collapsing under view ambiguity?

**HyperVis** is useful baseline pressure for scene-graph injection. Textual symbolic labels can be a lossy bottleneck; relation structure may need to stay continuous and modality-aligned.

**LatentSkill** is useful framing for agent skills. It suggests "skill memory" can become parameter-resident and modular, but the current evidence is still narrow enough that I would treat it as adjacent inspiration rather than a core cabbageland note today.

## One-paragraph takeaway

The best paper today is **PatchWorld** because it makes a world model into an executable belief-state object that can be inspected, tested, repaired, and used for planning. **Worth Remembering** is the best embodied-memory mechanism because it gives memory writes a causal surprise gate and beats same-budget uniform/random episodic storage. **LongSpace** is the benchmark/method to remember because it separates long-context video processing from real spatial memory. The common lesson is clean: useful memory is not accumulation, and useful world modeling is not reconstruction theater. The object being stored, updated, retrieved, or repaired has to be explicit enough to do work.
