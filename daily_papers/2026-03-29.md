# Daily Paper Digest — 2026-03-29

## Theme
Today’s worthwhile papers are about memory that actually changes the control or generation contract, not memory as a decorative synonym for “more context.” The strongest hit is a robotics paper that treats perceptual aliasing as the core failure mode and builds a geometry-grounded episodic memory around it. The second useful hit is adjacent rather than central: a video world-model paper that notices static-scene memory is too easy and designs a benchmark plus retrieval mechanism for dynamic subjects that leave and re-enter view.

## Short overview
Today’s most relevant paper is **Chameleon: Episodic Memory for Long-Horizon Robotic Manipulation**. It is not just another “memory-augmented VLA” paper. Its main value is that it names a real failure case—decision-time perceptual aliasing—and tries to preserve the disambiguating evidence instead of immediately compressing everything into semantic mush. The geometry-grounded write path and goal-directed recall story are more serious than most retrieval-by-similarity baselines.

The second paper worth preserving is **Out of Sight but Not Out of Mind: Hybrid Memory for Dynamic Video World Models**. This is not a robotics control paper, and I would not oversell the “world model” claim. But it does isolate an honest memory problem that many consistency papers glide past: when moving subjects disappear from view, static-scene retrieval is not enough. The dataset contribution is arguably as important as the mechanism.

A third paper I inspected but am **not** preserving as a full note today is **Persistent Robot World Models: Stabilizing Multi-Step Rollouts via Reinforcement Learning**. It looks competent and probably useful if you care about rollout fidelity, but the contribution is mainly post-training a video world model to make its long rollouts prettier and more stable. That matters for simulation quality, but it is weaker as a step toward explicit state, memory, or planning structure.

## Most relevant to cabbageland
**Chameleon** is the clear winner. The important move is not just “add memory.” The important move is to say that some robotic decisions are non-Markov at the observation level, then build the memory interface around preserving the evidence that disambiguates those cases. That is much more useful than generic long-context rhetoric.

## Novelty / framing / baseline impact
- **Perceptual aliasing as the right problem statement:** Chameleon is good framing material because it makes clear that memory failures in robotics are often failures to preserve disambiguating event structure, not just failures of context length.
- **Against text-only memory comfort:** Chameleon is a useful counterexample to the habit of reducing all long-horizon memory to semantic summaries.
- **Dynamic-memory benchmark pressure:** HyDRA / HM-World matter because many video-memory papers quietly optimize for static revisit consistency. Exit-entry dynamics are a stricter test.
- **What did and did not get inspected:** I inspected substantial accessible method text for **Chameleon**, **Hybrid Memory / HyDRA**, and **Persistent Robot World Models** via arXiv HTML, not just abstracts. I did **not** audit all appendices or every results table, so I am more confident in the architectural/mechanistic judgments than in exact metric margins.

## One-paragraph takeaway
The useful lesson today is that memory should be defined by what must survive ambiguity, not by how many tokens can be carried forward. **Chameleon** is the strongest paper because it identifies a concrete memory demand—perceptual aliasing in manipulation—and gives it a more defensible write/retrieve/control interface built around geometry-grounded evidence and goal-directed recall. **Hybrid Memory / HyDRA** is looser but still worthwhile because it notices that static-scene consistency is an easier problem than keeping track of moving entities that temporarily disappear. **PersistWorld**, by contrast, is mostly an optimization story for rollout fidelity: useful if you need better long generated videos, but not a major conceptual step toward explicit structure.
