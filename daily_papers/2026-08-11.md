# Daily Paper Digest - 2026-08-11

## Theme

Today's strongest papers all attack the same lazy assumption: if the model saw the right context, then the right state must already be there. **SpecPath** says requirement history is not the active contract unless the agent resolves it explicitly. **Latent Dynamics Reasoning** says video prediction is not a world model unless the system models how the latent state evolves rather than just regressing frames. **MMDiff** says multimodal capability is not controllable unless the adapted features themselves become intervention targets. **MedPixel** says medical reasoning is not properly grounded unless the language path and the pixel path share a verifiable interface. **AMIE (Video)** says clinical competence is not text competence with a webcam attached; audio-visual evidence changes the task.

## Short overview

This run used the live Tuesday, August 11, 2026 arXiv batch, with explicit non-robotics passes across agent evaluation, interpretability/control, and medical/clinical lanes. I inspected the arXiv HTML full text for all five ranked papers below.

Four papers earn preserved notes. **AMIE (Video)** is the strongest field-report runner-up: the evaluation is serious and the results are striking, but the preserve case is slightly weaker than the top four because the system details are less reusable and the evidence still depends on standardized patients rather than real deployment. **Most relevant today:** **SpecPath**.

## Ranked papers

### 1. **SpecPath: Testing Coding Agents Across Contract-Equivalent Specification Histories**

**Verdict:** must read.

Why it matters: It turns a vague complaint about agents getting confused by evolving requirements into a clean active-state problem. The useful move is to hold the repository, final contract, verifier, and budget fixed while varying only the path by which the contract is stated, then measure paired failures instead of average success.

### 2. **Learning How the World Evolves: Extrapolative Video World Models via Latent Dynamics Reasoning**

**Verdict:** must read direct paper.

Why it matters: It replaces "predict future frames" with explicit kinematic reasoning in a structured latent space. The useful move is to numerically integrate the lower-order dynamics and learn only the higher-order residual, which makes OOD extrapolation a real claim boundary instead of a slogan.

### 3. **Multimodal Model Diffing for Feature Discovery and Control**

**Verdict:** preserve-worthy direct paper.

Why it matters: It is one of the better recent multimodal interpretability papers because it makes feature discovery operational rather than decorative. The useful move is diffing a base-LM SAE against the multimodal-adapted model, then using task-specific contrastive firing to find causal features you can ablate or steer.

### 4. **MedPixel: A Unified Pixel-Language Model for Medical Reasoning and Segmentation**

**Verdict:** preserve-worthy adjacent paper.

Why it matters: It connects medical reasoning and dense grounding through a shared interface, then uses mask quality as an offline verifier for preference optimization. The useful move is not just unifying task formats, but aligning generated reasoning with actual pixel outcomes.

### 5. **Towards Expert-level Medical AI for Real-time Video Consultations**

**Verdict:** strong adjacent runner-up.

Why it matters: It is a serious multimodal clinical systems paper rather than a toy demo. The useful move is the asynchronous talker-planner-perception split plus a randomized video-OSCE evaluation against PCPs, but the preserve case is tempered by standardized-patient scope and less transferable underlying mechanism.

## Most relevant to cabbageland

**Most relevant today:** **SpecPath**.

This is the sharpest paper in the batch because it isolates a failure cabbageland should care about immediately: append-only conversational history is not the same thing as active state. The paper's central move, active-contract resolution, is exactly the kind of explicit-state framing that agent work keeps needing and evaluation keeps dodging. Aggregate accuracy barely changes across equivalent histories, but paired block analysis shows that more than a third of direct-success cases fail somewhere else once the same contract is expressed through revision history. That is a much better failure boundary than generic "long context" talk. It tells you what the agent must resolve before implementation even begins.

The rest of the batch reinforces the same broader taste. **LDR** makes latent dynamics explicit instead of hiding them inside frame regression. **MMDiff** treats multimodal capabilities as feature-level objects that can be isolated and intervened on. **MedPixel** turns medical grounding into a shared language-mask interface and uses pixel outcomes as real supervision for reasoning alignment. **AMIE (Video)** shows that clinically relevant perception is not just text chat with extra tokens.

## Novelty / framing / baseline impact

**SpecPath** is strongest because it finds the right evaluation unit. Direct FCR is **78.8%** and the mean over alternate histories is **78.7%**, so a standard leaderboard would call the system stable. But among **100** complete blocks that succeed on the direct specification, **35** fail on at least one contract-equivalent history, giving a **36.4%** task-macro any-CPV estimate. That is the important framing result: average success hides state-resolution failures because it destroys the pairing.

**Latent Dynamics Reasoning** is strongest because it makes extrapolation the main object rather than an accidental byproduct. At **256^2**, LDR cuts the ID-OOD gap in position error by **23.9x** under single-task training and **27.7x** under joint five-task training. Under joint training, the DiT-S baseline jumps from **0.086** ID error to **0.592** OOD error, while LDR moves only from **0.050** to **0.068**. It also does this with **4.1M** parameters instead of **106.1M** and runs **143x** faster at **256^2**.

**MMDiff** is strongest because it makes multimodal SAEs do causal work instead of just post-hoc labeling work. Ablating top spatial features drops VSR by roughly **10-15%** on average with almost no VQA spillover. On multimodal safety, top unsafe features cut attack success rate by **17-28%** per category, and across **1,061** candidate safety features the mean effect is **-9.67%** ASR with essentially zero VQA loss. On OCR, top-feature ablation gives a **-16.9%** mean category drop with low spillover, and MMDiff-CAA steering improves spatial and OCR over vanilla CAA by **+3.6%** and **+1.8%** on average.

**MedPixel** is strongest because it uses the right verifier. MedPLG-440K repurposes segmentation masks into roughly **440K** pixel-language training samples, and PLPO turns ground-truth mask quality into offline response preferences. The result is not just a broader prompt interface. MedPixel-7B beats strong baselines by **29.2 Dice** on reasoning segmentation and **40.7 Dice** on explanatory segmentation, reaches **76.0 Dice** on the interactive setting, improves zero-shot MeCoVQA-G+ slice Dice by **5.3** over BiomedParse, and stays stable under imperfect box prompts. The catch is also useful: the language is still template-derived and the setup remains mostly 2D and single-turn.

**AMIE (Video)** is strongest as a field-report runner-up because the evaluation is serious and multimodal. In a randomized OSCE with **100** scenarios, AMIE (Video) gets an **83%** overall case-rubric score versus **68%** for PCPs, **91%** top-1 diagnostic accuracy versus **77%**, and much stronger use of live video for physical observation and guided exam maneuvers. But it is still a standardized-patient study, not real clinical deployment, and the paper itself is upfront that fine anatomical precision, affective nuance, and continuous turn-taking remain weak points.

## One-paragraph takeaway

The common lesson today is that performance only becomes trustworthy when the operative state stops hiding in the margins. Requirement history has to be resolved into an active contract. Video prediction has to separate dynamics from appearance regression. Multimodal behavior has to become feature-addressable instead of just score-improvable. Medical reasoning has to ground itself in the pixels it claims to interpret. Even impressive clinical dialogue has to handle audio-visual evidence as something structurally different from text. The good papers are the ones that stop pretending more context is the same thing as better state.
