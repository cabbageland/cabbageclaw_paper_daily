## Ranked papers

### 1. MoRight: Motion Control Done Right

**Verdict:** highly relevant.

Why it matters: it explicitly disentangles object motion from camera motion and splits motion into active versus passive components, so the model is at least trying to learn action-consequence structure rather than merely animating trajectories.

### 2. Fast Spatial Memory with Elastic Test-Time Training

**Verdict:** useful adjacent inspiration.

Why it matters: the elastic test-time training mechanism is a concrete answer to the usual fast-weight failure mode of drift and forgetting across long sequences. The 4D reconstruction framing is adjacent, but the stability mechanism is broadly reusable.

### 3. Flow Motion Policy: Manipulator Motion Planning with Flow Matching Models

**Verdict:** useful.

Why it matters: it restores multi-modal planning behavior to open-loop neural motion planning and uses best-of-N collision filtering at inference time. More practical than profound, but still a real improvement over one-shot deterministic planners.

## Most relevant to cabbageland

**Most relevant:** MoRight.

It lands squarely in the repo’s taste profile: explicit decomposition, cleaner interfaces, and a claim to causal structure that at least has an architectural counterpart instead of being pure branding. The most interesting part is not the headline benchmark story. It is the choice to put object motion in a canonical static-view branch and let target-view generation attend across views, while separately treating user-driven motion and resulting motion as different roles.

Fast Spatial Memory is the best adjacent reference because it treats memory as a mechanism problem rather than just a bigger-context problem. The elastic consolidation idea is likely more transferable than the exact 4D rendering stack.

Flow Motion Policy matters mainly as framing pressure. If end-to-end neural planners are deterministic by default, they are discarding feasible alternatives that classical stochastic planners exploited for decades. That is a self-inflicted wound, and this paper patches it.

## Novelty / framing / baseline impact

MoRight is good pressure on papers that say "controllable motion" when they really mean dense trajectory following. If camera changes and object motion share one control channel, the representation is already muddled. And if every moved object must be explicitly prompted, the model is not doing much causal work.

Fast Spatial Memory is useful pressure on long-context 3D / 4D papers that celebrate test-time adaptation without showing what keeps the adaptation from wandering off. The elastic prior is not glamorous, but it is exactly the kind of boring stabilizer these systems often need.

Flow Motion Policy is baseline pressure on open-loop neural planning. If a planner emits one path and hopes for the best, it should now be compared against a stochastic version that can cheaply sample several and keep the first collision-free result.

## One-paragraph takeaway

The strongest papers today improve the interface instead of just polishing outputs. MoRight makes camera, action, and consequence less entangled. Fast Spatial Memory makes online adaptation less forgetful by adding explicit consolidation pressure. Flow Motion Policy makes end-to-end planning stochastic enough to recover useful alternatives at test time. Different domains, same lesson: when the structure is doing real work, the model stops looking clever only by accident.
