# Daily Paper Digest - 2026-07-06

## Theme

Today's useful pattern is **turn hidden state into an explicit contract**. AgenticSTS makes long-horizon agent memory a bounded, typed, ablatable prompt contract. HOLA gives linear attention a small exact cache for the key-value facts its recurrent state would otherwise smear away. Typographic-attack concept localization turns a VLM robustness failure into named attention circuits that can be intervened on. WorldDirector separates semantic 3D motion orchestration from visual rendering so off-screen objects keep moving instead of being hallucinated back into existence. Online safety monitoring calibrates a single verifier threshold so deployment alarms have a stated risk target.

I kept robotics and VLA work out of the ranked five today. I did scout that lane, including VT-WAM, Embodied.cpp, TAP for VLAs, ACID, WorldSample, LIME, Structured 4D Latent Predictive Models, and PhysMani. Several were relevant, and ACID / TAP remain worth remembering, but the non-robotics papers below had broader reusable mechanisms or cleaner evaluation surfaces. The scan also covered agent memory, linear-attention memory, interpretability, safety monitoring, neurosymbolic solver guidance, autonomous policy evolution, foundation-model training signals, generative world simulation, and medical / scientific ML.

## Ranked papers

### 1. **AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents**

**Verdict:** must read for agent memory evaluation.

Why it matters: AgenticSTS turns memory from an unbounded transcript habit into a five-layer retrieval contract: fixed protocol, state schemas / legal actions, game rules, episodic summaries, and triggered strategic skills. The important part is the evaluation surface. The paper is careful that the win-rate gains are directional, not statistically decisive, but the release makes memory layers auditable rather than mystical.

### 2. **A Hippocampus for Linear Attention: An Exact Memory for What the Recurrent State Forgets**

**Verdict:** strong architecture paper, preserve-worthy.

Why it matters: HOLA treats a linear-attention recurrent state as a compressor, not as an exact memory. It stores tokens with large delta-rule write magnitude, `beta * ||e||`, in a bounded KV cache and reads them through a sharpened cache path. That is a clean mechanism: let the model's own update residual decide what should escape compression.

### 3. **Towards Robustness against Typographic Attack with Training-free Concept Localization**

**Verdict:** strong interpretability-to-intervention paper.

Why it matters: the paper attacks a specific VLM failure mode: image text can hijack CLIP-style visual representations. The useful move is circuit-level: sample concept directions in attention-head subspaces, rank lexical-focus concepts with gradient attribution, then reweight or ablate the harmful heads. It is not just a defense; it is a small example of mechanistic diagnosis becoming a cheap runtime intervention.

### 4. **WorldDirector: Building Controllable World Simulators with Persistent Dynamic Memory**

**Verdict:** useful generative world-model paper, preserve-worthy with caveats.

Why it matters: WorldDirector separates the world-state planner from the video renderer. An LLM plans 3D object and camera trajectories, those plans become spatial controls for causal video generation, and appearance binding keeps off-screen dynamic objects visually stable when they re-enter. The caveat is domain gap from synthetic game-like data, but the design pattern is good: do not ask pixels alone to carry object permanence.

### 5. **Online Safety Monitoring for LLMs**

**Verdict:** lighter recommendation, but a useful deployment primitive.

Why it matters: the paper shows that a simple thresholded verifier signal calibrated with conformal risk control or high-probability bounds can compete with heavier sequential-monitor baselines for online LLM safety monitoring. The limitation is blunt and important: the monitor is only as good as the verifier signal. Token log probabilities were much weaker than a dedicated PRM in the factuality setting.

## Most relevant to cabbageland

**Most relevant today:** AgenticSTS.

The steal is the memory contract. For long-lived agents, memory should not mean "append whatever still fits" or "retrieve some vector-store mush." AgenticSTS frames each decision as a fresh prompt assembled from typed slots with different mutability and ablation roles. That is exactly the kind of interface OpenClaw-style agents need: what is fixed policy, what is current state, what is durable knowledge, what is episodic summary, and what is a reusable skill should be separated before the model sees it.

HOLA gives the same lesson at the architecture level: compressed state and exact memory should be different objects. Typographic-attack localization gives it at the interpretability level: find the circuits that carry the wrong feature, then intervene locally. WorldDirector gives it at the simulator level: persistent object trajectories should live outside the renderer. Online safety monitoring gives it at deployment time: thresholds should be calibrated against an explicit risk, not vibes.

## Novelty / framing / baseline impact

**AgenticSTS** is strong because it is unusually honest about evidence. It reports a bounded typed memory contract in Slay the Spire 2, releases 298 completed trajectories, and keeps the headline fixed-A0 comparison to a balanced 50-game subset. The largest observed difference is enabling triggered L5 skills: no-store baseline wins 3/10, while skill-enabled cells report 6/10. The authors explicitly say Fisher exact p is about 0.37, so this is not a statistically decisive win-rate claim. The value is the evaluation substrate: typed memory layers, frozen snapshots, prompt records, and condition tags make future memory-interface claims harder to handwave.

**HOLA** is strong because the mechanism matches the failure. Linear attention compresses history into a fixed recurrent state, which is cheap but lossy for exact key-value recall. HOLA adds a bounded exact cache selected by the delta-rule write magnitude and a decoupled RMSNorm-gamma cache read. On the reported 340M / SlimPajama-15B setup, Wikitext perplexity drops from 27.32 for the same-backbone GDN anchor to 22.92, and RULER single-needle recall at 32k is 0.58 versus 0.14 for GDN and 0.24 for a matched recency cache. The limitation is also clear: the cache is bounded, so needle-dense contexts and pure extraction still leave a gap to full attention.

**Typographic-attack concept localization** is strong because it turns a vision-language robustness failure into a mechanistic object. The method mines lexical-focus circuits in ViT attention heads using sampled concept vectors and a normalized text attribution score, then applies fixed interventions. Across five LAION CLIP ViT backbones, the reported object-classification gains under typographic attack are large, with much lower text-confusion rates and less than about 1% clean-accuracy tradeoff in the appendix. On LVLMs, the gains are smaller but still positive for Qwen3-VL and Gemma3 variants on RIO-Bench. The caveat is that the setup uses known or constructed text masks during circuit discovery, and the intervention is specific to this failure mode.

**WorldDirector** is strong because it refuses to let object permanence be an emergent accident. It uses an LLM as a 3D trajectory orchestrator, projects trajectories into 2D location controls, binds appearance from context, and generates video in causal chunks. Reported reconstruction metrics beat the listed causal world-model baselines, including PSNR 18.127 versus runner-up 14.782, and the appearance-condition ablation shows large drops in dynamic subject consistency. The caveat is domain realism: the authors note that synthetic game data can produce unnatural locomotion and blurry faces.

**Online Safety Monitoring** is useful because it is deployment-shaped. A single thresholded verifier signal is easy to run, and risk-control calibration gives explicit false-alarm or missed-detection targets. On MATH and harmful conversation datasets, CRC and UCB monitors empirically control the targeted risks and often detect earlier than heavier e-valuator-style baselines. The caveat dominates the paper: the proxy signal is the ceiling. A weak internal log-probability signal is cheap, but it loses substantial detection power compared with a dedicated process reward model.

**AutoMem** was a strong runner-up. Treating file-system memory operations as a trainable cognitive skill is exactly in-theme, and the reported 2x-4x gains across Crafter, MiniHack, and NetHack are hard to ignore. I did not preserve it today because AgenticSTS and HOLA made the memory point with cleaner evaluation / architecture mechanisms, while AutoMem's meta-LLM scaffold optimization is a larger system with more moving parts.

**G-RRM** was the best neurosymbolic runner-up. It uses recurrent reasoning models to guide exact symbolic solvers and shows when hints actually translate into speedups. I kept it out of the top five because the evidence is mostly Sudoku/SAT-specific, but the "neural proposer plus exact verifier" framing is worth revisiting.

**EvoPolicyGym** was another useful runner-up. It evaluates agents that iteratively edit executable policies under bounded environment feedback. The benchmark direction is good, but the current headline is more substrate than mechanism.

**Cache Merging as a Convergent Replicated State** was adjacent inspiration. The CRDT framing for KV-cache fragments is clever, especially duplicate absorption under re-delivery, but the paper's own k > 2 limitation makes it a narrower preserve today.

## One-paragraph takeaway

The best papers today all separate the thing doing compression from the thing that must stay inspectable. AgenticSTS separates agent memory into typed decision-time slots. HOLA separates exact recall from recurrent compression. Typographic-attack localization separates harmful lexical circuits from general visual perception. WorldDirector separates 3D semantic dynamics from video rendering. Online safety monitoring separates verifier evidence from calibrated alarm policy. The shared lesson is simple and portable: if state determines future behavior, make that state explicit enough to cache, retrieve, ablate, or calibrate.
