# Daily Paper Digest - 2026-06-09

## Theme

Today's useful pattern is **world models are becoming structured memory and action interfaces, not just future-frame generators**. **MemoryVLA++** is the most relevant paper because it gives a VLA an explicit past-present-future temporal interface: perceptual/cognitive memory for past context, current working tokens, and latent future imagination for action prediction. **iMaC** is the sharpest action-conditioning paper because it turns robot actions into rendered motion images and two contact-distance image streams instead of asking a video model to infer contact from a compact vector. **Latent Spatial Memory / Mirage** is the best video-world-model memory paper because it stores a 3D cache directly in diffusion latent space, avoiding the expensive RGB point-cloud render-and-reencode loop.

I inspected full PDFs for **MemoryVLA++: Temporal Modeling via Memory and Imagination in Vision-Language-Action Models**, **Latent Spatial Memory for Video World Models**, **iMaC: Translating Actions into Motion and Contact Images for Embodied World Models**, **Echo-Memory: A Controlled Study of Memory in Action World Models**, **AHA-WAM: Asynchronous Horizon-Adaptive World-Action Modeling with Observation-Guided Context Routing**, **omega-EVA: Envision, Verify, and Act with Latent Interactive World Models**, **Prisma-World: Camera-Controllable Multi-Agent Video World Model**, **MotionWAM: Towards Foundation World Action Models for Real-Time Humanoid Loco-Manipulation**, **FF-JEPA: Long-Horizon Planning in World Models with Latent Planners**, and **Your Model Already Knows: Attention-Guided Safety Filter for Vision-Language-Action Models**. MemoryVLA++, iMaC, and Latent Spatial Memory are preserved today.

**MemoryVLA++** is the strongest direct hit. It builds a full temporal VLA interface: current RGB and language become perceptual and cognitive working-memory tokens; a Perceptual-Cognitive Memory Bank stores low-level details and high-level semantics from past interaction; a manipulation-adapted video world model provides compact latent future imagination; and a diffusion action expert consumes the fused temporal tokens. The evidence is broad: Libero, SimplerEnv, Mikasa-Robo, Calvin, Libero-Plus, and several real-robot task categories. The paper is not perfectly controlled across all comparisons, but the ablations support the useful mechanism: both memory retrieval/consolidation and memory-guided imagination matter.

**iMaC** is the most concrete action-world-model interface paper. It asks a better question than whether generated robot videos look plausible: can a learned world model rank policy checkpoints in the same direction as real hardware? The method renders future robot motion from URDF and forward kinematics, predicts/uses depth, and builds two contact-image streams from scene-to-gripper and robot-to-scene distances. Across eight real-robot tasks, world-model scores are strongly positively correlated with real-world performance on most tasks, while the two weaker tasks expose missing-observation failure modes rather than generic metric noise.

**Latent Spatial Memory / Mirage** is the strongest memory-system paper for camera-controllable video world models. Instead of accumulating an RGB point cloud and repeatedly rendering it back to pixels before VAE encoding, Mirage stores VAE latent tokens at 3D world coordinates. Readout is a latent-resolution projection into the target camera view, then a ControlNet-style branch injects the memory into the diffusion backbone. The result is both a representation claim and a systems claim: better or competitive consistency on WorldScore and RealEstate10K, with much lower cache read cost and memory.

**Echo-Memory** is strong citation material and may deserve a later synthesis note. Its most useful result is that replay fidelity is not a proxy for revisit memory: spatial memory can win replay PSNR while failing open-domain return, and block-wise state-space recurrence can win semantic return while losing replay metrics. I am not preserving it as a full note today because it is mainly an evaluation/design-space study, while today's three notes provide more directly reusable architecture surfaces.

**AHA-WAM** is useful but not preserved. The two-timescale split between a slow video-DiT planner and fast action-DiT executor is a good deployment idea, and the latency story is concrete. I am treating it as adjacent because it is close to yesterday's action/world-model interface thread, and part of the result is systems optimization rather than a cleaner representation mechanism.

**omega-EVA** is also useful but not preserved. The proposal-conditioned Envision-Verify-Act loop is conceptually aligned with CAPE from June 8: make the policy inspect a latent consequence of its own proposed action before execution. The evidence is mostly simulation and the Stage 3 deltas are real but modest, so it is citation material rather than one of today's top three.

**Prisma-World** is adjacent for multi-agent video simulation. Its joint denoising, multi-agent RoPE, relative camera geometry, and minimap conditioning address cross-view consistency, but it is less directly tied to robot memory/planning than the preserved papers.

## Ranked papers

### 1. **MemoryVLA++: Temporal Modeling via Memory and Imagination in Vision-Language-Action Models**

**Verdict:** highly relevant, and the most relevant paper today.

Why it matters: it gives a VLA a real temporal interface: past memory, current working tokens, future latent imagination, and action prediction in one loop.

### 2. **iMaC: Translating Actions into Motion and Contact Images for Embodied World Models**

**Verdict:** highly relevant as an action-conditioned world-model evaluator.

Why it matters: it turns robot actions into spatial robot-body and contact-geometry controls, which is a much better interface than a dense action vector when contact decides the outcome.

### 3. **Latent Spatial Memory for Video World Models**

**Verdict:** highly relevant for video world-model memory and efficient 3D consistency.

Why it matters: it stores persistent spatial memory in the model's native latent space, making memory both cheaper and less lossy than RGB point-cloud caches.

## Most relevant to cabbageland

**Most relevant today:** MemoryVLA++.

The steal-worthy idea is not "add memory" or "add a world model." It is to divide temporal context by function. Current perception becomes working memory. Past interaction is retrieved from a compact memory bank that stores both perceptual details and cognitive semantics. Future state is represented by partially denoised latent world-model features rather than decoded video. The action expert gets a fused temporal representation instead of a raw stack of frames.

iMaC is the action-interface companion. If the world model must judge a candidate robot policy, the action condition should expose the robot's future body and the contact-relevant geometry. Motion images and contact images are clunky in a good way: they make the causal surface visible to the generator.

Mirage is the memory-system companion. If the generator already lives in latent space, a persistent 3D memory should not keep detouring through RGB. Storing latent tokens at world coordinates is the obvious idea after you see it, which is usually a good sign.

## Novelty / framing / baseline impact

**MemoryVLA++** raises the baseline for temporal VLA papers. A serious long-horizon VLA should say whether it has working memory, episodic retrieval, future imagination, or only a frame window. It should also show whether memory and imagination help different task families.

**iMaC** raises the baseline for embodied world models used as policy evaluators. If a world model claims to evaluate robot actions, compact action vectors are a weak interface unless the paper shows they preserve contact-sensitive differences. A better baseline now includes robot-rendered motion and explicit contact geometry.

**Latent Spatial Memory** raises the baseline for persistent-memory video generators. If a method stores RGB point clouds only to render and re-encode them at every conditioning step, it should justify why the model's own latent features are not the cleaner memory substrate.

**Echo-Memory** is a framing warning: replay metrics, in-domain return, and open-domain semantic revisit can disagree. Any future world-model memory paper that reports only replay fidelity is under-measuring the claim.

**AHA-WAM** is useful deployment framing: the world branch and action branch may need different temporal rates. Slow predictive context and fast control do not have to share one horizon.

## One-paragraph takeaway

The best paper today is **MemoryVLA++** because it makes temporal modeling in VLAs explicit enough to reason about: past memory, present tokens, and future imagination each have a job. **iMaC** is the action-conditioning note to remember because it converts actions into robot motion and contact geometry before asking a video model to simulate manipulation. **Latent Spatial Memory** is the video-world-model note to keep because it treats persistent 3D memory as latent features rather than RGB cache clutter. The common lesson is blunt: world models get more useful when their memory and action interfaces expose the structure that decisions actually depend on.
