# Daily Paper Digest - 2026-09-08

## Theme

Today's best papers are about making hidden handoffs testable. A memory store has to survive a model swap. A coding agent needs a pre-execution uncertainty signal before it burns a retry. A 3D world is not useful if it is one fused surface soup. A tool-use dataset should execute its dependencies, not merely believe a schema. A health benchmark should force models to read a user's longitudinal data instead of leaning on priors.

## Ranked papers

### 1. **Does Your Agent's Memory Survive a Model Upgrade? A Controlled Study of Memory Portability**

**Verdict:** must read direct paper.

Why it matters: This is the cleanest systems paper in the batch because it treats a model upgrade as a memory migration, not as a harmless endpoint replacement. The study separates writer, reader, embedder, and repair source across 48 synthetic histories and four memory formats: raw history, RAG chunks, compressed notes, and fixed-schema KG records. The headline result is exactly the kind of annoying engineering truth agent systems need: fixed schemas transfer almost unchanged, while free-form notes are directionally coupled to the model that wrote them. KG-fixed changes by only about 0.04 percentage points after a writer swap, but NOTES shifts by +9.91 or -13.28 points depending on direction. The RAG result is just as useful: a 50/50 mixed embedding index captures only 4.96 points of an 11.90-point full re-embedding gain, silently throwing away most of the upgrade.

### 2. **How to Speculate about Uncertainty in Agentic Coding? A Draft-Model Gate Method**

**Verdict:** must read direct paper.

Why it matters: This paper has the right deployment instinct: stop discovering bad tool actions only after execution. Speculative Uncertainty uses a small open-weight draft model to score a black-box coding agent's already-generated trajectory, splits reasoning and action spans because they carry different failure signals, and feeds those features into a lightweight failure-likelihood gate. The method does not beat white-box trajectory calibration, but it gets close enough to matter while using only output tokens. On SWE-Bench Verified and DA-Code, the simple veto gate cuts execution error from 21% to 15% and 14% to 6%, while reducing token cost by 14-19%. The caveat is important: task success does not improve and even drops on SWE-Bench Verified, so this is a cost-and-risk gate, not a magic competence booster.

### 3. **WorldSculpt: Generating Compositional Worlds from Grounded Videos**

**Verdict:** highly relevant direct paper.

Why it matters: WorldSculpt attacks a real limitation in current generated worlds: a gorgeous 3D scene is much less useful if every object is fused into one undifferentiated representation. The mechanism is strong. For each object, it builds an anchor-aligned canonical frame, lifts multi-view DINOv3 features into a voxel grid, fuses them with a permutation-invariant IBR-style aggregator, and injects the condition into a Pixal3D object prior adapted with LoRA. The result is a world-frame collection of separate meshes rather than one monolithic scene. The new UE-MeshyScene benchmark is also worth preserving: six Unreal Engine scenes, 2,299 objects, 5,964 views, and exact per-object mesh ground truth. On that benchmark, WorldSculpt beats ShapeR on all reported metrics, including F-Score 0.951 vs. 0.813.

### 4. **Multi-Step Tool-Calling over Korean Open Public APIs: A Benchmark and a Data-Synthesis Recipe**

**Verdict:** highly relevant direct paper.

Why it matters: This paper earns the fourth slot because it refuses to synthesize tool-use trajectories from plausible-looking dependency edges alone. KOPA-Bench covers 145 tasks over six domains of live Korean public APIs, with average five tool calls, up to 14, and 59% involving parallel execution. EDGE builds a dependency graph over tool outputs and inputs, then uses live execution evidence to keep, update, or prune edges before generating trajectories. That detail matters: only 50.2% of the LLM-judged skeleton edges execute, while the refined graph reaches 62.7%, and the pruned edges execute only 14.8% of the time. Training small Qwen3.5 models on the EDGE data raises KOPA pass@1 from 0.18 to 0.31 for 4B and from 0.33 to 0.43 for 9B, nearly matching an untuned 27B model.

### 5. **WearableQA: A Benchmark for Health Reasoning over Real-World Wearable Data**

**Verdict:** strong adjacent paper.

Why it matters: WearableQA is not a mechanism paper, but it is a good benchmark paper because it exposes a specific failure: models can often recite health priors more easily than they can compute from a noisy personal time series. The benchmark has 4,084 ten-option questions from 200 real users with up to 500 days of daily wearable measurements, blood biomarkers, demographics, and cohort-relative context. Its 16 question types separate data reasoning from health reasoning and single-signal from cross-signal reasoning. Across 14 models, accuracy spans 19.6% to 72.9% against 10% chance. The useful diagnostic result is that tool access changes the problem: for GPT-5.4, Python access raises overall accuracy from 51.2% to 71.3%, while alternate text or chart renderings barely help. That says the bottleneck is not presentation polish; it is computation over longitudinal evidence.

## Novelty / framing / baseline impact

**Memory portability** matters because it turns "will the new model remember?" into separate writer-reader, embedding, retrieval, and repair tests.

**Speculative Uncertainty** matters because it provides a black-box pre-execution failure signal for tool-using coding agents without repeated sampling or logits.

**WorldSculpt** matters because it treats generated worlds as addressable object collections, not just visually plausible fused geometry.

**KOPA / EDGE** matters because it makes live execution evidence part of the data-synthesis loop for multi-step tool calling.

**WearableQA** matters because it distinguishes health-prior recall from actual computation over a user's longitudinal physiological record.

## One-paragraph takeaway

The September 8 lesson is that persistence and structure only count when the handoff survives contact with the next component. A memory format has to be readable by tomorrow's model. A coding-agent trajectory has to expose risk before the shell or tool call runs. A world representation has to keep objects separable if downstream systems will edit or simulate them. A tool-call corpus has to prove that a dependency edge works against the live endpoint. A health benchmark has to force measurement-grounded reasoning, not just medical fluency. The common pattern is simple: if the boundary is important, instrument the boundary.
