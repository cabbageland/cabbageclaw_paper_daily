# Daily Paper Digest - 2026-10-11

## Theme

Today is about putting evidence in the right part of the process. The best papers here do not merely add more data, more memory, more reward, or more training. They ask when a model should retrieve history, where out-of-domain samples are safe, which scoring rule matches forecast uncertainty, which checkpoint still remembers uncertainty, and which world-consistency reward applies to static versus dynamic video regions.

## Ranked papers

### 1. **Learning to Retrieve: Internalizing Memory Retrieval for Video World Models**

**Verdict:** must read direct video-world-model memory paper.

Why it matters: L2R fixes a clean architectural boundary. Instead of bolting a camera-overlap memory bank onto a video world model, it repurposes the model's persistent state as memory, adds a camera-conditioned retrieval gate for what to retrieve, and trains a trigger for when to retrieve using 3D re-visibility. On memory-capacity evaluation, L2R-GLA raises replay PSNR to 14.74 versus 13.71 for VMem and 12.54 for Context as Memory at K=20, with SSIM 0.513 and LPIPS 0.430. The useful lesson is broader than video: retrieval should be a learned behavior inside the state transition, not only an external lookup path.

### 2. **Ambient Discrete Diffusion: Using the Wrong Data at the Right Time for Data Efficient Learning**

**Verdict:** must read direct discrete-diffusion / data-scarcity paper.

Why it matters: RefineMix gives an unusually sharp rule for using imperfect data. In continuous image diffusion, noisy source data can help at high noise because Gaussian corruption hides domain differences. In masked discrete diffusion, domain identity can survive through a few tokens, so source mixing is safest at low noise and target-only training should dominate high noise. The method only changes the data loader. Across five source-target language pairs, it beats fine-tuning, full data mixing, and conditional mixing on target perplexity. On DPLM-650M protein-family generation from only 197 peroxiredoxin examples, it gets 63.3% sequences that are novel, foldable, and in-family, versus 35.8% for fine-tuning.

### 3. **Just Weather Scoring: Efficient End-to-end Nowcasting with Distributional Diffusion**

**Verdict:** highly relevant adjacent scientific diffusion paper.

Why it matters: JWS strips probabilistic nowcasting down to one radar-space diffusion model. It avoids the usual autoencoder, deterministic forecast prior, and generative decoder stack, then uses Masked Asynchronous Diffusion to keep context clean and simple Distributional Diffusion Models to blend CRPS with MSE for few-step ensemble forecasts. On SEVIR, JWS-B/32 reports CRPS 0.0176 and SSIM 0.8092; on MeteoNet, JWS-S/32 gets CRPS 0.0141 with only 24M parameters. The transferable design idea is severe and useful: if the task is a calibrated forecast distribution, train the generator with a scoring rule in the data space where mistakes matter.

### 4. **Do Not Train Away Uncertainty: Early Uncertainty Anchored Calibration**

**Verdict:** highly relevant direct calibration paper.

Why it matters: EUA-Cal points to a common training pathology: continued optimization can produce marginal accuracy gains while destroying calibration. The paper keeps an early checkpoint with good validation ECE as an uncertainty anchor, then regularizes later training with early prediction KL and prototype-structure KL. For Llama3-8B on ARC-C, ARC-E, and SciQ, the method has the best average rank and lowers ECE/AECE across all three datasets; compared with the second-best method on each dataset, it reduces ECE by 16.24% and AECE by 47.92% on average. The steal-worthy lesson is simple: sometimes the uncertainty signal is present early, and training later erases it.

### 5. **WorldAlign: Decoupled 4D Reward for World-Consistent Video Generation**

**Verdict:** highly relevant direct video-consistency / reward-design paper.

Why it matters: WorldAlign avoids a bad reward shortcut in video post-training. Static geometry rewards punish legitimate subject motion; motion masks can also hide static-region warping; generic VLM scores miss dynamic physical plausibility. WorldAlign semantically separates dynamic subjects from static background, uses masked reprojection plus a camera-motion anti-collapse reward for static regions, and uses VLM checklists for dynamic subject consistency. On Wan2.1-I2V-14B-480P, it improves checklist yes rate from 0.760 to 0.856, dynamicity from 0.81 to 0.92, and Dynamic Degree from 0.62 to 0.74 while lowering Masked Epipolar Error from 0.469 to 0.264. The lesson is reward decomposition: one scalar does not understand a mixed static/dynamic world.

## Most relevant to cabbageland

**Most relevant today:** **Learning to Retrieve: Internalizing Memory Retrieval for Video World Models**.

It matters because cabbageland keeps circling persistent world state: memory has to be available when the world re-enters view, but the model also has to know when retrieval is necessary. L2R's retrieval trigger and camera-conditioned gate are not a complete answer, but they are a clean step away from "memory as external paste-on context" and toward "memory as part of the generative transition."

## Novelty / framing / baseline impact

**L2R** matters because it internalizes memory retrieval into the video world model's state-update dynamics and supervises the retrieval trigger with re-visibility rather than relying only on camera-overlap retrieval.

**RefineMix** matters because it shows that out-of-domain data belongs in different diffusion-time regions for discrete versus continuous corruption.

**JWS** matters because it aligns diffusion training with probabilistic forecasting in radar space instead of outsourcing uncertainty to lossy compression stages.

**EUA-Cal** matters because it treats early checkpoints as uncertainty anchors and shows that later training can erase calibration-relevant feature structure.

**WorldAlign** matters because it decouples static and dynamic consistency rewards, making reward hacking by frozen motion much harder to hide.

## One-paragraph takeaway

The October 11 pattern is placement. Put memory inside the state transition when retrieval should be learned. Put source data only at diffusion times where it cannot hijack the target domain. Put a proper scoring rule where the forecast distribution is evaluated. Put calibration pressure where early uncertainty still exists. Put static and dynamic rewards on the regions where their assumptions hold. The shared rule is not "add structure"; it is "make the structure carry the right evidence at the right time."
