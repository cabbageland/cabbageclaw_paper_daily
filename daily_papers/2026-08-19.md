# Daily Paper Digest - 2026-08-19

## Theme

The strongest papers today all attack fake equivalence between a container and the state it is supposed to carry. A parsed view is not the workspace. Row accuracy is not evidence grounding. A JSON state field is not a state mechanism. Shared weights are not cross-task concept usability. Stacked frames are not memory.

## Short overview

This Wednesday, August 19, 2026 run used arXiv HTML full-text inspection for all five ranked papers below. Four papers earn preserved notes. **Action-Effect Memory Pretraining** is the one robotics paper worth carrying today, but it stays just below the preserve bar because the mechanism is better than the ecology: the gains are real, but the evidence still lives inside a fairly narrow benchmark-and-policy stack. **Most relevant today:** **StagedWorkspace**.

## Ranked papers

### 1. **StagedWorkspace: A Versioned Workspace for Knowledge-Work Agents**

**Verdict:** must read direct paper.

Why it matters: This is the cleanest agent-systems paper in the batch because it operationalizes a failure mode that usually gets buried under harness chatter: the agent can search one version, edit another, review a third, and submit a fourth. Instead of hand-waving about better tools, it defines a workspace-state contract tying parsed records, native artifacts, staged diffs, and submitted outputs to explicit versions. In paired ablations, dual parsed/native access improves OfficeQA Pass@1 by **8.3-12.1** points and APEX mean score by **4.7-9.2** points; with Gemini 3.1 Pro the system reaches **63.9%** on OfficeQA versus a published same-model row of **29.3%**.

### 2. **PathoArgus: Advancing Evidence-Grounded Long-Context Visual Reasoning across Gigapixel Whole-Slide and Multi-Slide Case Contexts**

**Verdict:** preserve-worthy direct paper.

Why it matters: This is the right embarrassment benchmark for long-context pathology QA because it asks whether the answer follows the evidence set, not whether the model can farm row-level multiple choice. PathoArgus-Bench contains **22,078** questions from **4,913** patients across **15** TCGA projects. GPT-5.6 reaches **57.09%** overall and **57.04%** ESG accuracy, but only **19 of 483** controlled evidence quartets are fully correct, or **3.93% QExact**. The companion reader reaches **50.39%** overall and **46.17%** ESG but only **1.86% QExact**, which is exactly the useful bad news: better access is not the same as grounded use.

### 3. **Explicit State Elicitation Is Not Enough: A Controlled Audit of Memory-Policy Classification**

**Verdict:** preserve-worthy direct paper.

Why it matters: This paper makes the right severe methodological move: it audits the benchmark and isolates the intervention before selling a structured-output story. On a frozen **160**-example controlled set with **40** matched four-way families, adding an explicit state-output field yields only **+0.6** points for Llama and **+3.3** for GPT-OSS, both non-significant. Taxonomy exposure helps more than state emission, which is precisely the problem: the gain mostly looks like label-structure leakage, not a faithful intermediate mechanism. The useful conclusion is brutal and correct: explicit state elicitation needs more than bolting a JSON field onto a routing prompt.

### 4. **Where a New Concept Must Enter: Entry Point Gates Cross-Task Usability in Unified Multimodal Models**

**Verdict:** preserve-worthy adjacent paper.

Why it matters: This is the strongest multimodal concept-transfer paper in the batch because it separates architectural transfer from overlapping supervision. A concept bound through only one task direction transfers only if it enters shared computation in the right semantic format. An alignment probe predicts export across **36** configurations with **rho = +0.68**; a closed-form activation edit works at layer **7 of 28** and becomes indistinguishable from base behavior by layer **14**; and a mid-stack alignment objective acquires the concept with only **0.1%** relative loss of general text-to-image ability versus **41%** for the standard generative route.

### 5. **Action-Effect Memory Pretraining for Robot Manipulation**

**Verdict:** adjacent inspiration, not yet preserve-worthy.

Why it matters: This is the one robotics paper today with a real mechanism rather than memory-branded frame stacking. AEM compresses interleaved vision-action history into a single Mamba-encoded final-token memory and uses masked reconstruction to force action-state structure into that bottleneck. On RoboTwin2.0 it lifts Diffusion Policy from **29.8%** to **50.5%** and ManiFlow from **9.8%** to **29.1%**, while beating direct feature stacking on both efficiency and randomized-scene success. It stays below the preserve bar because the evidence remains tightly tied to its chosen policy families and benchmark ecology.

## Most relevant to cabbageland

**Most relevant today:** **StagedWorkspace**.

Its core claim is exactly right for mixed-format agent work: artifact quality is downstream of state discipline. If parsed search, native edits, diffs, and submission do not point to the same evolving workspace state, then "good agent performance" becomes partly a bookkeeping illusion. The same taste shows up elsewhere in the digest. **PathoArgus** says answer accuracy is not enough unless predictions move with evidence. **Explicit State** says emitting a state label is not enough unless it actually improves the decision. **Where a New Concept Must Enter** says shared parameters are not enough unless the concept enters shared computation in a usable semantic format. Same moral across domains: the system has to keep the operative state live, not merely mention it.

## Novelty / framing / baseline impact

**StagedWorkspace** matters because it turns artifact-state synchronization into an explicit experimental variable rather than invisible harness plumbing.

**PathoArgus** matters because ESG quartets and QExact punish models that keep answer priors while ignoring controlled evidence changes.

**Explicit State Elicitation** matters because it audits dataset shortcuts and bundled prompt changes before claiming that structured intermediate fields help.

**Where a New Concept Must Enter** matters because it reframes multimodal transfer around entry-point location and shared semantic format, not just weight sharing or more joint training.

**Action-Effect Memory Pretraining** matters because it argues for action-conditioned compact memory rather than naive history stacking in manipulation policies.

## One-paragraph takeaway

The August 19 lesson is that state has to stay operational all the way through the computation. A workspace contract has to preserve which artifact version the agent actually saw and changed. An evidence benchmark has to preserve whether the answer moves when the evidence moves. A memory-policy audit has to preserve the difference between answer-associated labels and real intermediate reasoning. A multimodal model has to preserve a concept at a site where both tasks can still use it. A robot memory has to preserve action-conditioned temporal structure rather than just append more frames. Same severe conclusion all day: do not confuse the object that stores the claim with the mechanism that makes the claim usable.
