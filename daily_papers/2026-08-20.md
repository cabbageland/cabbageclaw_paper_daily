# Daily Paper Digest - 2026-08-20

## Theme

The best papers today all punish fake equivalence between a container and the state it is supposed to carry. A task bundle is not the realized environment state. Attention weights are not candidate-specific visual evidence. An endpoint-conditioned bridge is not the Markov information the sampler can actually see. A semantically equivalent codebase is not equivalent for a code agent. An updated harness is not the same thing as retained capability.

## Short overview

This Thursday, August 20, 2026 run used arXiv HTML full-text inspection for all five ranked papers below. Four papers earn preserved notes. **Harness Continual Learning** stays just below the preserve bar because the external-state framing is genuinely useful, but the evidence still leans on a broad harness abstraction and a fairly synthetic task-stream ecology. **Most relevant today:** **FACET**.

## Ranked papers

### 1. **FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis**

**Verdict:** must read direct paper.

Why it matters: This is the cleanest terminal-agent synthesis paper in the batch because it makes a simple but usually hidden rule explicit: the instruction, initialized environment, reference solution, and verifier need to be generated from the same realized executable state, not from loosely aligned intermediate drafts. FACET validates **6,078** tasks with an average of **22.77** executable checks per task, then uses **1.2K** successful trajectories to fine-tune Qwen3.5 models. On Terminal-Bench 2.1, the resulting gains are real and data-efficient: **+7.12** for 4B, **+8.24** for 9B, and **+6.75** for 27B, with the 27B model reaching **47.57**, only **1.49** points below a **397B** Qwen row under the same evaluation setting.

### 2. **ReWEIGH the Evidence: Calibrating Token-Level Ordinal Visual Evidence to Mitigate Hallucinations in Large Vision-Language Models**

**Verdict:** preserve-worthy direct paper.

Why it matters: This is one of the best hallucination-mitigation papers in the batch because it asks the right question at decode time: not whether the model is confident, and not where attention points, but whether the current candidate token has unusually weak support in the internal visual states. ReWEIGH uses rank-based evidence pooling plus token-specific calibration from unlabeled images, and it does so without retraining. Across four 7B backbones it cuts hallucinated object mentions by up to **21.3%** with only **1.33%** average added latency per token, and the reductions extend across **11** models spanning **6** architecture families up to **32B**.

### 3. **Bridge Graphical Models: Coupling, Projection, and Current-Preserving Dynamics for Generative Modeling**

**Verdict:** preserve-worthy adjacent paper.

Why it matters: This paper is valuable because it isolates a structural bottleneck that continuous-time generative papers often blur away: the bridge used during training can condition on endpoints, but the deployed sampler only sees current state and time. The Markovization gap turns that compression loss into a measurable design object before training. On a CIFAR-10 proxy diagnostic computed in about **9 minutes** on CPU, straight independent coupling scores **3.25** while straight minibatch OT scores **2.34**; the lower-gap choice then also lowers downstream pilot train loss from **0.182** to **0.168** and FID from **50.48** to **49.17**. On Fashion-MNIST the same ranking is cleaner, with FID dropping from **30.14** to **21.96**.

### 4. **A Jagged Frontier: Evaluating Robustness of Code Agents to Semantics-Preserving Transformations**

**Verdict:** preserve-worthy direct paper.

Why it matters: This is the strongest code-agent robustness paper in the batch because it does not confuse stochastic variance with robustness loss. The authors build a library of **14** semantics-preserving transformations, evaluate **54** SWE-bench instances, and use paired repeated runs to isolate perturbation effects from normal agent randomness. The average resolve-rate degradation is modest but real, reaching **6.7** percentage points in the worst affected configurations, with statistically significant drops in **6 of 16** scaffold-model-dataset combinations. The more important result is structural: robustness rankings do not transfer across scaffolds, and even when solve rate barely moves, cost can still rise by up to **22.9%**.

### 5. **Harness Continual Learning: Continual Adaptation Beyond Model Parameters**

**Verdict:** adjacent inspiration, not yet preserve-worthy.

Why it matters: This paper makes the right conceptual move by treating prompts, memories, capability maps, and routers as an evolving agent state around a frozen model rather than pretending all continual learning lives in weights. Its guarded update-and-commit framing is also sensible. The results are nontrivial: textual-reasoning final average rises from **45.50%** zero-shot to **64.70%** under the plastic profile with only **0.07** average forgetting, and multimodal final average rises from **39.40%** to **68.92%** under the stability profile. It stays below the preserve bar because the abstraction is broad enough to hide many degrees of freedom, and the evidence still lives inside a fairly curated harness/task ecology rather than a harsher deployment setting.

## Most relevant to cabbageland

**Most relevant today:** **FACET**.

It makes the most reusable systems claim in the batch: if the artifact bundle does not share a realized executable state, then both training data and evaluation numbers get polluted by bookkeeping drift. The same severe taste echoes through the rest of the digest. **ReWEIGH** says candidate confidence is not the same thing as candidate evidence. **Bridge Graphical Models** says endpoint-conditioned bridge structure is not the same thing as what a Markov decoder can recover from current state. **Jagged Frontier** says semantic equivalence for a repository is not semantic equivalence for a scaffolded agent. Same lesson all day: use the operative state, not the decorative proxy.

## Novelty / framing / baseline impact

**FACET** matters because it turns shared executable state into the controlled variable instead of leaving it as invisible synthetic-data plumbing.

**ReWEIGH** matters because it replaces generic confidence heuristics with candidate-specific ordinal evidence calibrated per token.

**Bridge Graphical Models** matters because it reframes continuous-time generative design around an irreducible bridge-to-Markov compression gap that can be estimated before training.

**A Jagged Frontier** matters because it shows robustness is jointly a property of model, scaffold, and workload, not a scalar trait of the model alone.

**Harness Continual Learning** matters because it formalizes harness-level forgetting and makes external-state retention an explicit deployment decision rather than an accidental side effect.

## One-paragraph takeaway

The August 20 lesson is that a system should be evaluated against the state it can actually act on, not against the larger object we casually say it is using. FACET grounds task artifacts in one realized container state. ReWEIGH grounds candidate tokens in token-specific visual evidence rather than uncalibrated confidence. Bridge Graphical Models grounds generative design in the information a Markov sampler can truly access after endpoint compression. Jagged Frontier grounds robustness in paired perturbation tests rather than headline benchmark rows. Harness Continual Learning grounds continual adaptation in mutable external state rather than frozen slogans about learning. Same underlying rule: stop awarding mechanism credit to proxies that do not survive contact with the actual operative state.
