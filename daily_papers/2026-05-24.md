# Daily Paper Digest — 2026-05-24

## Theme

Today’s useful pattern is **planner-facing or policy-facing state repair**. The strongest direct paper is **EvoScene-VLA** because it gives chunked robot control an explicit recurrent scene prior that is updated by the model’s own predicted actions and then corrected by the next observation. **Repairing Latent World Models with Horizon-Matched Trajectory Reachability Metrics** is the sharpest mechanism paper because it shows, in a very controlled way, that a world model can contain the right state while the planner still sees the wrong metric. **Stream3D** is the best adjacent 3D paper because it keeps long monocular 3D generation grounded in retained evidence instead of dragging an ever-growing latent cache through time.

## Short overview

Brave Search was unavailable in this environment because no Brave Search tool is configured for this run. AlphaXiv was also not used as a live discovery surface here, so discovery fell back to direct recent arXiv API/category inspection and arXiv HTML full-text reads.

I inspected the arXiv HTML full text for **EvoScene-VLA**, **Repairing Latent World Models with Horizon-Matched Trajectory Reachability Metrics**, **Pre-VLA**, and **Stream3D**. Confidence is good on central mechanism, framing, and headline results, and weaker on appendix-level implementation details I did not audit line by line.

**EvoScene-VLA: Evolving Scene Beliefs Inside the Action Decoder for Chunked Robot Control** is the most relevant paper today. Its core claim is that chunked VLA policies keep acting on stale scene assumptions between visual refreshes, because actions themselves change contact state, occlusion, and geometry inside the chunk. EvoScene-VLA responds by carrying a recurrent scene prefix across chunks, letting the decoder co-denoise both the next action chunk and a compact scene update, then feeding that scene update forward as the next prior. This is a real structural move, not just more temporal tokens. The caveat is that the system is still fairly scaffolded, with geometry teachers and a training-only future-scene predictor doing a lot of support work.

**Repairing Latent World Models with Horizon-Matched Trajectory Reachability Metrics** is the cleanest mechanism paper of the batch. The paper shows that a latent world model can encode position almost perfectly and still fail at planning because raw terminal Euclidean distance underweights the tiny latent subspace that actually matters for reachability. The proposed fix is post-hoc and narrow on purpose: learn a small horizon-matched pairwise metric from trajectory separations, then swap that in as the terminal candidate-ranking score while holding the world model, optimizer, and manifests fixed. I like this paper because it attacks a real interface failure instead of assuming better representations will automatically expose better control geometry.

**Stream3D: Sequential Multi-View 3D Generation via Evidential Memory** is adjacent rather than directly embodied-control relevant, but it is still worth keeping in view. Instead of transporting hidden generator state across a long monocular stream, it stores a bounded memory of high-evidence historical views selected from cross-attention behavior and reuses those as conditioning views for a frozen 3D generator. That is a better story than latent-cache accumulation, although it is still a wrapper around single-object 3D generation rather than a richer persistent scene model.

**Pre-VLA** looked initially relevant, but it lands lower for me. The runtime verifier is practical and probably useful, yet the paper is mostly a safety filter around candidate action chunks rather than a more legible state, memory, or planning mechanism. It feels more like a deployability patch than a structural advance.

## Most relevant to cabbageland

**Most relevant today:** EvoScene-VLA: Evolving Scene Beliefs Inside the Action Decoder for Chunked Robot Control.

The useful part is not just that it says “scene beliefs.” The useful part is the specific job contract for those beliefs. The model keeps a recurrent scene prefix, refines that prefix against the new observation, then uses the action decoder to jointly denoise both actions and the next scene state. That means the representation passed to the next control call is not just remembered perception and not just predicted future video, but an action-updated prior that the next observation is allowed to correct.

That is exactly the kind of structural move cabbageland usually wants: something explicit enough that you can ask what state is being carried, how actions update it, and where correction enters. I do not think EvoScene-VLA is the final clean architecture, because the training stack leans on a scene predictor and geometric anchoring teachers that disappear at inference. But the paper still earns attention because it treats stale within-chunk world state as a real systems problem and gives the decoder a concrete mechanism for handling it.

## Novelty / framing / baseline impact

**EvoScene-VLA** sharpens an important baseline question for chunked VLAs: does the policy carry an action-updated world prior across chunks, or does it merely remember past images and then guess again? Papers that only add temporal context without letting actions explicitly update carried state now look less satisfying.

**TRM** changes a different part of the framing. It says that “the representation contains the information” is not enough. The planner only gets the metric interface you expose to it. If the reachability-relevant subspace has low energy under raw latent MSE, a perfectly probeable state can still produce terrible candidate ranking. That is a useful warning for a lot of joint-embedding world-model rhetoric.

**Stream3D** mostly matters as a representation-management lesson. If you want long streaming consistency, it may be better to retain bounded explicit evidence than to keep hauling opaque latent baggage forward and praying it stays calibrated.

## One-paragraph takeaway

The best paper today is **EvoScene-VLA** because it gives chunked robot control an explicit, action-updated scene prior that persists across control calls and is corrected by fresh observations. **Repairing Latent World Models with Horizon-Matched Trajectory Reachability Metrics** is the sharpest mechanism paper because it cleanly demonstrates that a world model can encode the right state while exposing the wrong control metric to the planner. **Stream3D** is the best adjacent paper because it uses bounded evidential memory instead of latent-state drift for streaming 3D generation. The shared lesson is that persistent internal structure only matters if it changes the actual decision interface, whether that interface is a recurrent scene prior for action or a terminal metric for planning.
