# Daily Paper Digest - 2026-08-12

## Theme

Today's strongest papers all attack the same lazy assumption: if a model has state, then the system already knows what that state means and how to trust it. **Rollback Repair** says a bad memory is not a bad row; it is a contaminated dependency graph that needs explicit repair. **ReTree** says search state is not a transcript; it has to remember where evidence entered and what downstream reasoning depends on it. **ConfTriage** says confidence is not deployable just because a model can say a number; it has to be calibrated and attached to a deferral policy. **VidForensics-M1** says evidence supervision should come from verifiable temporal intervals rather than model-written rationales. **MAP-Graph** says shared memory is not governance unless provenance can filter, rerank, and gate actions.

## Ranked papers

### 1. **From Faulty Memories to Corrected Actions: Dependency-Guided Rollback Repair for Memory-Augmented Agents**

**Verdict:** must read direct paper.

Why it matters: It treats bad memory as contaminated downstream state rather than a bad record to delete. The useful move is explicit dependency tracing, independent-support checking, and answer-relevant replay, which turns repair into a state-management problem instead of a "please be more careful" ritual.

### 2. **Self-Correcting Long-Horizon Search Agents via Tree-Structured Memory**

**Verdict:** must read direct paper.

Why it matters: It turns search memory into an editable evidence tree with source-bound facts and contradiction-triggered pruning. The useful move is locating where a refuted claim entered the state, then rebuilding only the descendants that actually depended on it.

### 3. **ConfTriage: A Calibration-Aware LLM Triage Framework for Pulmonary Nodule Malignancy with Selective Specialist Deferral**

**Verdict:** preserve-worthy adjacent paper.

Why it matters: It gives a cleaner deployment recipe for medical LLM triage than most clinical multimodal work. The useful move is not just asking an LLM for a diagnosis, but calibrating the model's verbalized confidence in logit space and routing low-margin cases to a specialist backstop with explicit guarantees.

### 4. **VidForensics-M1: Meta-Detection Reinforcement Learning with Verifiable Temporal Grounding for AI-Generated Video Forensics**

**Verdict:** preserve-worthy adjacent paper.

Why it matters: It replaces model-written explanation rewards with verifiable temporal evidence. The useful move is Evidence-Guided Reward Redistribution, which redistributes label reward according to temporal-grounding quality rather than trusting a synthetic rationale just because it sounds forensic.

### 5. **MAP-Graph: Provenance-Aware Shared Memory for Multi-Agent Workflows**

**Verdict:** strong direct runner-up.

Why it matters: It separates permission, trust, and action risk inside a typed provenance graph. The useful move is recursive ancestry evaluation plus risk-sensitive gating, but the benchmark is synthetic and the exact-decision story is weaker than the task-success headline.

## Most relevant to cabbageland

**Most relevant today:** **From Faulty Memories to Corrected Actions: Dependency-Guided Rollback Repair for Memory-Augmented Agents**.

This is the sharpest paper in the batch because it attacks the place persistent-memory systems actually rot: not at retrieval time alone, and not at answer time alone, but in the propagated state between them. A poisoned or stale memory can alter claims, tool plans, answers, and later writes. The paper's central move is to stop pretending that deleting the source or rewriting the last answer solves that. Instead it builds a typed memory-to-action graph, traces downstream dependencies, preserves nodes with independent trusted support, and selectively replays only the answer-relevant affected computation.

That is exactly the kind of state discipline cabbageland keeps needing. On the controlled benchmark, the method reaches **85.3%** recovery versus **77.3%** for the strongest competing repair baseline, while removing all diagnosed faulty memories, preserving all benign memories, and replaying much less than the judge-style repair baseline. On the adapted LongMemEval-V2 subset, it reaches **68.0%** recovery versus **54.0%** for the next best method, while also posting the strongest claim-invalidation F1. The paper is not claiming perfect trace reconstruction, and the benchmark still assumes an upstream fault diagnosis. But the framing is right: fault removal is not state recovery.

The rest of the batch reinforces the same broader taste. **ReTree** makes search memory source-addressable and revisable at the claim-introduction point. **ConfTriage** makes model confidence operational by calibrating it and attaching it to a deferral policy. **VidForensics-M1** uses evidence the system can actually verify instead of explanations it merely likes. **MAP-Graph** pushes shared memory toward policy-governed provenance rather than semantic retrieval alone.

## Novelty / framing / baseline impact

**Rollback Repair** is strongest because it chooses the right repair unit. On the controlled benchmark it reaches **85.3%** recovery versus **77.3%** for LLM-judge repair, while cutting replay ratio from **0.217** to **0.123** and LLM calls from **9.80** to **5.70**. On the adapted LongMemEval-V2 subset it reaches **68.0%** recovery versus **54.0%** for the next best baseline. The main framing result is simple and useful: once faulty memory has already propagated, deleting the bad source is not the same thing as repairing system state.

**ReTree** is strongest because it turns contradiction repair into a state edit rather than a context-compression side effect. Across **2,149** questions, it reaches **44.0%** overall judge accuracy and **28.0%** EM, beating Full-Trajectory ReAct by **13.9** judge-accuracy points and the strongest aggregate bounded baseline by **3.0** points. On the FRAMES attribution diagnostic it reaches **42.8** CiteF1 with **14.8%** uncited claims, versus **31.5** and **33.1%** for Full-Trajectory ReAct. The important lesson is that bounded context only works if the system preserves where facts came from and what later reasoning depends on them.

**ConfTriage** is strongest because it turns LLM confidence into a real routing policy instead of a pretty side channel. The paper calibrates verbalized confidence in logit space, cuts ECE from **0.085** to **0.042**, and at threshold **tau = 0.28** lets the LLM resolve **76.5%** of cases while deferring **23.5%** to the specialist backstop. It reports **88.22%** F1 and **0.92** AUC. The sharper framing result is the ablation: natural-language radiology descriptions carry the signal, while low-level image statistics are basically diagnostically useless for the tested LLM setup.

**VidForensics-M1** is strongest because it makes evidence supervision verifiable. On ViF-Bench, the temporal-grounding version reaches **82.83%** accuracy, **73.16%** recall, and **81.00%** F1, improving over plain label RL by **10.30**, **9.74**, and **11.21** points respectively. It also beats explanation-based RL by **6.25**, **6.38**, and **6.96** on the same metrics. On the fake-only GenBuster subset, temporal grounding improves recall by **10.1** and **19.2** points on the OOD and Wild evaluations over label-only RL. The real contribution is not "better video forensics" in the abstract; it is the demonstration that reward should depend on evidence quality when the evidence is checkable.

**MAP-Graph** is a useful runner-up because it pushes provenance from audit metadata into runtime control. It reaches **94.96%** task success, **72.70%** exact decision accuracy, **90.22%** clean success, and **0%** attack success, leakage, and revocation violation inside its benchmark. The reason it stays a runner-up is that the benchmark is fully synthetic and the exact-decision story is less overwhelming than the task-success headline. It is still a good design paper, just not the one to preserve over today's sharper repair and evidence papers.

## One-paragraph takeaway

The useful August 12 lesson is that state only becomes trustworthy when the system can name where it came from, what depends on it, and what to do when it turns out to be wrong. Bad memories need dependency-aware rollback, not cosmetic rewriting. Search state needs introducers and descendants, not just summaries. Clinical confidence needs calibration plus a deferral boundary, not vibes. Evidence-aware reward works better when the evidence is a verifiable interval rather than a plausible story. Shared memory needs provenance that governs action, not just retrieval. Same lesson everywhere: stop treating state as text that happens to be lying around.
