# Daily Paper Digest - 2026-08-16

## Theme

The strongest papers today all reject the lazy idea that a long trajectory is already a usable state. **LongHorizon-Harness** says progress should persist as audited task state, not as an ever-growing executor transcript. **RippleMem** says memory access should recover missing support, not just return the first relevant-looking record. **Beyond Myopic World Models** says long-horizon prediction should be trained at the horizon where it will be used, not by recursively hoping short-horizon losses somehow survive rollout. **TRACES** says science benchmarks are still ducking the more basic question of whether a model can reject a rotten premise. **NeuroMosaic** says clinical multimodal reasoning should route through anatomy-indexed evidence and abstention logic, not generic pooled visual tokens.

## Short overview

This Sunday, August 16, 2026 run used live recent-paper discovery and arXiv HTML full-text inspection across long-horizon agents, persistent memory, world models, scientific reliability, and non-robotics medical multimodal reasoning. I inspected the arXiv HTML full text for all five ranked papers below.

Three papers earn preserved notes. **TRACES** is the strongest runner-up because the benchmark is sharp and the failure signal is ugly in the useful way, but it is still mostly a measurement instrument rather than a reusable systems mechanism. **NeuroMosaic** is the strongest adjacent runner-up because the anatomy-indexed routing, concept memory, and abstention boundary are real, though the evidence remains cohort-bound and domain-specific. **Most relevant today:** **LongHorizon-Harness**.

## Ranked papers

### 1. **LongHorizon-Harness: Advancing Long-Horizon Agents for Real-World Tasks**

**Verdict:** must read direct paper.

Why it matters: This is the sharpest systems paper in the set because it treats long-horizon execution as explicit task-state management rather than heroic context stuffing. The useful move is the Manage-Execute-Audit loop: a manager writes bounded contracts from audited state, a fresh-context executor performs one round, and a read-only auditor decides what actually changed. On matched backbones, it lifts Qwen 3.7-Plus from **51.8%** to **80.7%** on WeaveBench, from **69.7%** to **77.2%** on Terminal-Bench 2.1, and from **2.8%** to **8.3%** binary completion on OSWorld 2.0.

### 2. **RippleMem: From Isolated Retrieval to Associative Recollection for Long-Term Agent Memory**

**Verdict:** must read direct paper.

Why it matters: This is the best memory paper in the batch because it names the real failure mode: the evidence exists, but the system fails to recover all of it together. RippleMem stores cue-rich episodic memory units, links them in an event-centric graph, then uses recalled anchors as cues for bounded associative expansion. It reaches **87.14%** judge accuracy on LoCoMo, **84.80%** and **86.60%** overall accuracy on the two LongMemEval-S settings, and cuts graph-construction cost by about **30x** relative to heavier graph-memory baselines.

### 3. **Beyond Myopic World Models: Long-Horizon End-to-End Training for Direct Future Prediction**

**Verdict:** preserve-worthy direct paper.

Why it matters: The paper's useful claim is that the main bottleneck is often the supervision horizon, not the world-model brand name. DPWM predicts the endpoint in one shot from the initial observation plus the whole action sequence, avoiding recursive rollout at both training and inference. On the policy-trained Cheetah setting at horizon **100**, endpoint MSE is **0.4452** for DPWM versus **25.6086** for ADM and **11.0004** for MoSim, and the authors further show that recurrent baselines also improve when retrained under the same endpoint objective.

### 4. **TRACES: A Benchmark for Epistemic Reliability in Scientific Reasoning by LLMs**

**Verdict:** strong direct runner-up.

Why it matters: This is one of the better recent benchmark papers because it measures the refusal boundary instead of assuming scientific QA scores imply scientific judgment. TRACES builds **42** probes from retracted, fraudulent, and pseudoscientific papers and evaluates **30** models across **12,600** responses. Every tested model fails more than **71%** of agentic probes, **22 of 30** fail more than **90%** of the time, and about **81%** of responses contain no warning at all.

### 5. **NeuroMosaic: Anatomically Grounded Multimodal Large Language Modeling for Molecularly Aware Glioma Reasoning from 3D MRI and Clinical Narratives**

**Verdict:** strong adjacent runner-up.

Why it matters: This is the non-robotics paper worth keeping in view because it replaces generic visual pooling with anatomy-indexed routing plus a concept memory that can explicitly say unresolved. The model converts multi-sequence MRI into routed regional evidence, binds diagnostic clauses to image or clinical support, and calibrates abstention separately from representation learning. It reports external integrated-subtype macro-F1 values of **0.784**, **0.761**, and **0.742**, plus evidence-pointing accuracy of **0.703** and a targeted-deletion confidence drop of **0.187** versus **0.046** for random deletion.

## Most relevant to cabbageland

**Most relevant today:** **LongHorizon-Harness**.

It attacks a very cabbageland problem with the right unit of repair. Long tasks usually fail because execution history, progress tracking, and completion judgment all get stirred into the same context soup. This paper separates them cleanly. The executor is no longer trusted to both act and narrate what is true. Only audited state survives the round.

That is a good design rule well beyond GUI agents. The useful transferable ideas are bounded contracts, fresh-context execution, state records that persist outside the trajectory, and a rule that completion is only granted by read-only environmental evidence. **RippleMem** sharpens the same taste from the memory side: stored history is not enough unless the system can recover the missing support set. **Beyond Myopic World Models** makes the parallel point for predictive models: even a strong representation can fail operationally when training pressure lands at the wrong horizon.

## Novelty / framing / baseline impact

**LongHorizon-Harness** matters because it makes task state a first-class object rather than a side effect of the transcript. The paper's real contribution is not yet another planner loop. It is the decision to let only audited facts persist across rounds.

**RippleMem** matters because it changes the memory question from "did retrieval find something relevant?" to "did recollection recover an answerable support set?" That is a cleaner and more useful boundary than another flat top-k retrieval comparison.

**Beyond Myopic World Models** matters because it humiliates a common reflex. If long-horizon behavior depends on endpoint accuracy, then training only on one-step losses and hoping rollout will carry the signal is structurally misaligned.

**TRACES** matters because it exposes a hole in scientific-agent evaluation. A model can score well on answerable science questions and still operationalize fraud, pseudoscience, or retracted premises when asked to help do science with them.

**NeuroMosaic** matters because it treats medical multimodal reasoning as evidence routing plus selective risk, not as "feed the MRI to a bigger decoder." The anatomy-indexed route and unresolved state are the interesting parts, not the generic multimodal branding.

## One-paragraph takeaway

The useful August 16 lesson is that long-horizon competence does not live in the raw trace. It lives in what the system can isolate, verify, and reuse. Good memory should recover missing support, not just matching snippets. Good execution should preserve audited task state, not a swollen transcript. Good world models should be trained at the horizon where they will actually be judged. Good scientific assistants should know when the premise itself is rotten. Good clinical multimodal systems should bind conclusions to routed evidence and keep abstention explicit. Same taste everywhere: make the operational state legible, or the system will eventually lie to itself.
