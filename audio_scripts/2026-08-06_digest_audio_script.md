Most relevant today: EA-Graph: Artifact-Anchored Verification Memory for Coding Agents under Upstream Drift.

This paper hits a real continuity failure in coding agents: one session can verify a behavior against a specific upstream state, another session inherits the claim after the upstream has drifted, and the workspace still looks superficially healthy. EA-Graph's core move is severe and correct. It does not store "we checked this." It stores claims anchored to sub-path artifact identities and the exact content digests that justified those claims. When the supporting artifact changes, the claim is not politely caveated. Its freshness is revoked, and if the replacement content is unavailable, the paper insists on unprovable instead of a fake binary guess. That is the right instinct for agent memory systems that need to survive handoffs, upstream drops, and partial visibility without bluffing.

The rest of the batch reinforces the same taste from other angles. SafeCommit says action release should depend on explicit alternative worlds, not on one confident narrative. The Calibration Floor says evaluation should separate content change from format rescue before talking about reasoning. CRS-Triage says defer logic should internalize missingness, disagreement, and asymmetric risk. Mimir says long-horizon control improves when progress state and scene belief stop living in one mushy latent bucket.

EA-Graph is strongest because it refuses file-level and prose-level invalidation. In the paper's worlds, file-granularity review marks about 88 of 96 behaviors as suspect when only about 17 are actually affected. In the Haiku round, artifact-anchored memory beats both prose notes and no persistent memory in all seven worlds, with exact paired p = 0.0156 against each control.

SafeCommit is strongest because it reframes action release as a set-valued safety question. At alpha = 0.05, single-world acting reaches a 41.2% unsafe-commit rate, while full SafeCommit gets that down to 2.6% with 97.4% task success. The important lesson is that certification without probing is too conservative, and probing without certification is too loose.

The Calibration Floor is strongest because it attacks the measurement boundary directly. On 12 admitted cells with live extraction failures, format effects exceed content effects with one-sided Wilcoxon p = 1.7e-3. The constrained-decoding control closes a median 71% of the gap between the naive total effect and the content-margin estimate, and the frontier arm still shows zero content margin in all five checked cells despite positive total deltas.

CRS-Triage is strongest because it treats selective prediction as a clinical risk problem rather than a generic abstention problem. At 80% coverage, its CRS score cuts expected triage penalty from 0.267 with evidential certainty to 0.208, and under-triage from 5.9% to 4.7%. The useful framing move is that disagreement between modalities should raise fused uncertainty, not get averaged away.

Mimir is strongest because the ablations show the memory split is doing real work. On EB-Habitat with Qwen3-VL-32B, removing world memory drops success from 71.5 to 12.5, while removing task memory drops it to 46.5. That is a much more convincing argument than just saying "we added memory and scores went up."

The common lesson today is that systems get brittle when a compressed summary is allowed to masquerade as the state transition it came from. Verification memory should keep artifact-level anchors, not only conclusions. Action release should range over plausible worlds, not one confidence number. Self-correction claims should survive decomposition into content and format margins. Clinical deferral should reflect reliability and asymmetric harm, not only uncertainty magnitude. Embodied agents should keep task progress and world belief as separate writable objects. The good papers are the ones that replace mushy proxy state with an explicit object you can revoke, inspect, or route on.
