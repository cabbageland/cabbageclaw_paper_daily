Most relevant today: Why Does the Future Branch? Identifiable Closure Tests for Stochastic Physical World Models.

The paper attacks a genuinely important ambiguity in world modeling. A stochastic predictor may look well calibrated while hiding two very different stories: either the observation is missing state that would make the future more determinate, or the declared state is already complete and the world really does branch. Those imply different interventions. One calls for refinement, memory, or sensing. The other calls for preserving multiple futures. ClosurePairs gives a protocol for separating the two, then shows that the distinction changes downstream routing decisions even when total predictive variance is matched. That is exactly the kind of explicit-state versus real-stochasticity distinction cabbageland keeps caring about.

The other strong papers reinforce the same taste from different angles. PMMC makes memory access plans explicit before the query arrives. Don't Offer What Can't Be Done makes state-feasibility checks deterministic instead of hoping the model remembers them. What Carries the Signal forces an overdecorated pathology pipeline to compete against simpler controls. Measurement Without Validity argues that benchmark pipelines need the same suspicion turned on themselves.

Why Does the Future Branch? is strongest because it shows that good predictive likelihood is not enough. The baseline lesson is severe: two systems with identical predictive distributions can require opposite interventions.

PMMC is strongest because it does not just say "better memory." The useful framing move is to shift part of multimodal memory reasoning from online retrieval into offline compilation plus execution-backed verification.

Don't Offer What Can't Be Done is strongest because it separates topical relevance from executability. The baseline lesson is that semantic tool retrieval is not a safe proxy for whether a production skill can actually run.

What Carries the Signal is strongest because it puts a fashionable image-genomics story under held-out patient controls and shows exactly where the signal stops. The baseline lesson is that driver-count gene lists and geometric stories are cheap unless they beat composition, scanner, and simple linear alternatives on held-out patients.

Measurement Without Validity is strongest as framing. The baseline lesson is that IRR, simulation calibration, and construct validity are not paperwork; they determine whether the score means much at all.

The common lesson today is that if a hidden support structure matters, it should be represented or audited directly. World models should separate hidden-state aliasing from true process noise. Memory systems should compile evidence-access strategies rather than leaving everything to last-minute retrieval. Tool agents should gate impossible actions before the model sees them. Foundation-model biology claims should be tested against held-out patients and brutal competing controls. Benchmarks should report how valid the measurement pipeline is, not only the final number. The papers worth keeping are the ones that stop treating these support structures as implementation details and make them legible enough to contest.
