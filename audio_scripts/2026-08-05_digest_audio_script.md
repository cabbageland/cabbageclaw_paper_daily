Most relevant today: TraceCompiler: Skill-Guided Mining and Compilation of LLM Agent Traces into Mostly Deterministic Workflows.

This paper is aimed right at a recurring agent-systems problem that cabbageland keeps circling: agents rediscover procedures they have already executed, but blindly replaying or summarizing old traces preserves too much accidental garbage. TraceCompiler treats reuse as a compilation problem under partial observability. It clusters recurring intents, strips retries and exploratory clutter, verifies dependencies at the argument level rather than by adjacency, types remaining bindings, and leaves only genuinely open choices as residual LLM nodes. The best case study is honest and useful: a Venmo money-request intent shrinks from 34 observed API calls to 11 runtime calls, while the bad case study is even more important because the compiler refuses to compile an irreversible Spotify and Todoist workflow whose branching logic was never observed. That refusal instinct is exactly the right standard.

The other strong papers reinforce the same deeper taste from different angles. Uncertainty Is Not Enough says a routing policy should estimate the value of the next computation, not just its confidence deficit. TARL says memory updates should be treated as typed state transitions, not as one binary commit bit. Preferred, Not Safer says evaluation needs to separate what humans like from what is safe enough to deploy. Cross-Anesthetic ECoG says a transfer failure diagnosis should tell you whether to learn new features or simply move the threshold.

TraceCompiler is strongest because it refuses the default event-log lie that "next in time" means "depends on." The baseline lesson is severe: adjacency and directly-follows statistics are weak proxies for executable structure when arguments, retries, and missing outputs are all in play.

Uncertainty Is Not Enough is strongest because it separates uncertainty from recoverable uncertainty. At matched compute it improves the average commonsense score from 77.5 for CARE to 78.1, while also lowering ECE from 0.051 to 0.042 and AURC from 0.099 to 0.087. The useful framing move is that the routing state should estimate marginal risk reduction, not just entropy.

TARL is strongest because it turns memory updating into an executable semantics problem instead of a retrieval embellishment problem. The baseline lesson is brutal: even gold binary Write/Hold supervision plus heuristics only reaches 0.4539 next-state accuracy and 0.1059 conflict preservation, while TARL reaches 0.6521 and 0.5376 by predicting the finer transaction directly.

Preferred, Not Safer is strongest because it does not merely complain about leaderboards. It quantifies the failure. In the paper's snapshot, the most preferred model still shows 18.0% harmlessness failures and 18.4% accuracy failures, while cardiology ECG reaches an 89.9% dangerous rate. The baseline lesson is that preference can be a style score wearing a safety costume.

Cross-Anesthetic ECoG is strongest because it localizes the failure. Ketamine keeps a session AUROC of 0.98, but the inherited threshold sits at chance and a baseline-anchored threshold lifts balanced accuracy from 0.50 to 0.85. The baseline lesson is that richer representation and domain adaptation are the wrong reflex if the real bug is threshold drift.

The common lesson today is that a system should not be allowed to hide its real state transition behind a convenient scalar or binary proxy. Recurring traces need evidence-backed dependency structure, not event order. Modular expert routers need value-of-information estimates, not generic uncertainty panic. Long-term memory needs executable update types, not a write bit. Clinical evaluation needs direct failure accounting, not preference worship. Cross-domain decoding needs threshold diagnosis, not automatic representation escalation. The papers worth keeping are the ones that replace a mushy proxy with a more explicit object you can inspect, contest, and route on.
