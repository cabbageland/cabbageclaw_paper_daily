MemTrace is the most relevant paper today. It changes the unit of long-term memory evaluation from independent QA rows to knowledge points: a single user fact probed across age, question type, and evidence condition. The important result is not merely that memory systems forget. It is that most hard failures are evidence-use failures after relevant evidence is already reachable.

Vision-language models for chest radiography do not always need the image is the strongest healthcare/evaluation paper in the scan. The paper builds an interventional audit using label-matched image swaps, radiologist-box target masks, and irrelevant masks to test whether a correct answer causally depends on the radiograph. The uncomfortable result is that a text-only model lands close to the best multimodal system, and several medical VLMs either ignore the image or use it only selectively.

Rift is the most provocative interpretability paper today, but I am keeping it below the two preserved notes because it needs replication and has a narrow experimental regime. The mechanism is interesting: residual rank rises during deceptive forward passes relative to both honest answers and naive wrong answers. The paper controls for wrongness and tests roleplay, strategic bluffing, concealment prompts, length, and cross-domain probes. That is worth attention. It is not yet a deployment-ready lie detector.

Several other papers were useful but stayed below the preservation line. ProvenanceGuard is highly aligned with MCP-style agents because it verifies not just whether a claim is supported somewhere, but whether it is attributed to the right tool/source. PARSE is a practical warning that prompt-injection defenses proven on synthetic tasks may collapse on real enterprise documents. DivInit is a clean agent-search trick: diversify first-turn queries before parallel rollouts instead of letting threads collapse onto the same retrieval path. Dissecting model behavior through agent trajectories is valuable as an agent-harness paper, but the paper is partly a systems report around one harness. SpeechDx is a strong benchmark contribution for clinical speech AI, but today's two preserved notes have sharper mechanism transfer.

Most relevant today: MemTrace.

The direct steal is the unit-of-evaluation shift. Instead of asking whether an agent answered a row correctly, hold a durable fact fixed and vary time, query type, and evidence condition. That maps almost perfectly onto real assistant memory: current-state questions, historical-state questions, change-over-time questions, absent-evidence refusal, and false-premise correction are not interchangeable.

The second steal is the reach/use split. A memory system can retrieve the right span and still fail because the generator is not given temporal structure, conflict structure, or an explicit enough interface to use it. That is a design warning for any long-lived cabbageland agent: storage and retrieval are not memory unless the evidence is presented in a form the reasoning loop can bind to the answer.

The chest-radiography paper contributes the evaluation analogue: a correct answer is not enough. Intervene on the supposed input channel and test whether the answer changes for the right reason. For medical VLMs, that means swapping or masking images. For agents, it could mean withholding a tool observation, swapping a source, masking a retrieved span, or altering a stated memory.

MemTrace raises the bar for memory benchmarks. It makes pooled QA accuracy look too blunt because it cannot tell whether a system remembers a current value, an earlier value, a trajectory, an absent fact, or a contradicted premise.

Chest radiography VLM audit raises the bar for medical multimodal evaluation. Reported VQA accuracy should not count as visual grounding unless interventional tests show the model used the image. This is especially important because text-only priors can look clinically competent on common yes/no finding probes.

Rift is a useful framing paper for deception interpretability: wrong output is not the same variable as internal conflict. The naive-liar control is the key design idea. The red flag is scope: small-to-mid models, simple facts, prompt-induced deception, and limited extraction. Keep the mechanism, not the hype.

ProvenanceGuard and PARSE are deployment reminders. Agents need source ownership, not just pooled support, and retrieval sanitization should be tested on real professional documents rather than toy prompt-injection strings.

DivInit and EnvRL point in the same agentic direction from opposite ends: diversify the evidence path before rollout collapse, and use environment transitions as training signal rather than treating outcome reward as the whole story.

The best papers today are all refusing a lazy metric. MemTrace says memory is not row-level accuracy; it is fact-level behavior across time, question type, and evidence condition. Chest radiography VLMs do not always need the image says medical VQA accuracy is not evidence of image use; grounding needs causal intervention. Rift says wrongness is not the same as deception; compare a model lying while knowing against a model that is merely wrong. The shared lesson is simple and useful: before trusting a success number, identify the mechanism that was supposed to produce it and test that mechanism directly.
