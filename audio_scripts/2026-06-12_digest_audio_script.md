Welcome to the June 12, 2026 Paper Daily at Cabbageland.

Today's useful pattern is world models are being judged by the interfaces they expose to control, not by rollout aesthetics alone. WEAVER is the strongest paper because it treats a robotic world model as a learned simulator that must support policy evaluation, synthetic policy improvement, and test-time planning under latency constraints. MaskWAM is the cleanest object-centric WAM paper: masks are both a future prediction target and an optional first-frame spatial prompt, so the model predicts what matters, not only what happens. EA-WM is the predicate-level companion: it adds event prediction and verification on top of feature-space rollouts so a planner can score imagined futures by task progress rather than feature distance alone.

WEAVER, MaskWAM, and EA-WM are preserved today.

WEAVER is the best direct hit. Its central claim is practical and useful: a manipulation world model should jointly satisfy fidelity, temporal consistency, and inference speed because the downstream uses are policy evaluation, policy improvement, and online planning. The architecture combines multi-view visual latents, proprioception prediction, sparse long-term memory, short-term history, flow-matched latent dynamics, diffusion-forcing style noise, accelerated denoising, and latent reward/critic heads. The paper is strongest where it connects the world model to decisions: predicted rollouts correlate with real success after finetuning, synthetic segments improve a pi0.5 policy without extra real interaction, and latent best-of-4 steering improves test-time task success.

MaskWAM is the strongest object-centric WAM interface paper. It treats masks as first-class latent streams, jointly predicting future RGB, future masks, and action chunks. That makes target regions explicit during training and enables a deployment-time mask prompt for language-ambiguous manipulation. The best result is not the tiny LIBERO gain over other strong baselines; it is the ablation showing that a mask prompt without future-mask prediction collapses in ambiguous tasks, while joint mask prediction plus prompting stays robust across distractors, novel instances, and lighting shifts.

EA-WM is worth preserving with caveats. The mechanism is exactly aligned with explicit-state taste: roll out candidate actions in frozen visual-feature space, decode task-grounded event predicates, and score futures with task, semantic, physical, and uncertainty terms before CEM or hybrid selection. The red flag is that event supervision is simulator-derived, LIBERO online evaluation is short-window rather than full autonomous episodes, and Goal10 gains are modest. Still, the design pattern is useful: visual-feature closeness is not the same as event progress.

RepWAM is directly relevant but not preserved as a separate note today. It trains a representation visual-action tokenizer aligned to a visual foundation model, then learns latent actions as transitions inside that semantic visual space. The ablations are useful, especially the two-stage latent-action training result, but the paper overlaps with the last few days of WAM interface/alignment papers and is less sharply explicit than MaskWAM or EA-WM.

NavWAM is strong adjacent direct work for navigation. It represents current state, goal image, future observations, action chunk, future state, and goal-progress value as a shared latent canvas inside a Cosmos Predict2-style video model. It beats CEM-style navigation world-model baselines and reports 19/24 real-world image-goal navigation successes. I am not preserving it today because the strongest cabbageland thread is manipulation/world-action interfaces, but NavWAM is good citation material for "future prediction is useful when trained with action and value targets."

World Tracing is the best 3D/geometry paper in the batch. It predicts layered pixel-aligned 3D point stacks, where layer 0 is the visible surface and deeper layers complete occluded intersections along each input ray. This is a serious representation paper, especially for input-faithful hidden geometry, but it is adjacent to today's robotics-control thread rather than the main preserved story.

SpatialClaw, SPARC, and VISA are useful citation material. SpatialClaw argues that code in a persistent kernel is a better spatial-reasoning action interface than single-pass code or fixed tool calls. SPARC scores robot-demo annotations by phase-aware object motion, 3D gripper proximity, and robot-overlap filtering. VISA converts offline VLM object audits into voxel-grounded semantic supervision for 3D occupancy world models. All three are useful, but none displace today's WAM/control-interface papers.

Real-Time Execution with Autoregressive Policies, See Selectively, Act Adaptively, and LabVLA / RoboGenesis are mostly baseline/framing material for deployment, bimanual routing, and synthetic lab robotics data. The ideas are useful, but they are less central than today's top three.

Most relevant today: WEAVER.

The steal-worthy idea is to evaluate a world model by the jobs it can perform for a policy. Does it predict the robot's proprioceptive state, not just pixels? Does it maintain enough memory to survive occlusion and long-horizon manipulation? Can a reward or value model score the imagined latent directly, without decoding every frame and asking a separate judge? Can synthetic rollouts actually improve the base policy, and can online planning run within a latency budget?

MaskWAM adds the object-centric interface lesson. If a policy is supposed to act on the cup, drawer handle, bottle, or contact patch, the world model should carry that target region as a state variable. A future mask is a better training signal than asking the action head to infer relevance from unconstrained RGB futures.

EA-WM adds the task-progress lesson. If the important event is "drawer opened," "object moved," "object on target," or "contact condition satisfied," then a planner needs those events exposed as predicted predicates or verifier scores. Feature-space closeness can be useful, but it is too blunt to stand in for task logic.

WEAVER raises the bar for manipulation world models. A serious baseline should report not only visual FVD/FID, but whether imagined rollouts correlate with real task success, whether synthetic segments improve a policy, and whether test-time search is fast enough to matter.

MaskWAM raises the bar for WAM grounding. RGB-only WAMs should now be compared against object-centric mask prediction or equivalent explicit target-state supervision, especially in cluttered or language-ambiguous tasks. Prompting alone is not enough; the model must be trained to propagate the prompted state into future prediction and action.

EA-WM sharpens the baseline for feature-space planning. If a feature world model is used for CEM or MPC, the scoring function should be checked against task predicates, physical margins, and event progress, not only terminal representation distance. The caveat is that the paper's own deployable evidence is still preliminary.

RepWAM is useful for novelty framing around semantic visual-action tokenizers and latent actions. It supports the claim that reconstruction-oriented tokenizers are a weak default for WAMs, but it does not replace the need for explicit object or event interfaces.

NavWAM is useful for arguing that future-view prediction should be coupled to action and value targets when the task is closed-loop navigation.

The best paper today is WEAVER because it asks whether a world model can do real policy work: evaluate trajectories, generate useful synthetic improvement data, and steer actions online quickly enough to matter. MaskWAM is the clean object-centric complement, showing that predicting and prompting masks gives the action head a target-specific interface instead of a generic RGB future. EA-WM is the event-level complement, using predicted predicates and verifier scores to judge whether imagined futures make task progress. The common lesson is blunt: world models become useful when their hidden state is exposed as the right control object, whether that object is a value-scored latent rollout, a future target mask, or a task-event scorecard.
