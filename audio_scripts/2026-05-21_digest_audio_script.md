Today’s strongest signal is explicit interfaces that actually constrain behavior. The best paper is ECHO: Continuous Hierarchical Memory for Vision-Language-Action Models because it tries to make long-horizon memory retrieval more typed and hierarchy-aware instead of treating memory as a flat nearest-neighbor sludge heap. Jointly Learning Predicates and Actions Enables Zero-Shot Skill Composition is the more intellectually honest neurosymbolic paper today, because it does not pretend end-to-end action generation alone will magically support composition. GaussianDream is useful adjacent material, but it overclaims the phrase “world model” for what is mostly a geometry-heavy training-time supervision scaffold.

I fully inspected arXiv full text for ECHO, Jointly Learning Predicates and Actions Enables Zero-Shot Skill Composition, and GaussianDream. Confidence is solid on their mechanisms, training setup, and headline results, and weaker on fine implementation details I did not separately re-derive from appendices.

ECHO is the most relevant paper today. Its core move is to store successful robotic experiences in a continuous hyperbolic hierarchy, retrieve them with entailment-aware tree search, and fuse the retrieved memory back into a frozen π0-style policy through residual injection and gating. The part that matters is not “hyperbolic” by itself. The useful claim is that long-horizon reuse gets better when memory is organized by abstraction level instead of thrown into a flat retrieval pool.

Jointly Learning Predicates and Actions Enables Zero-Shot Skill Composition is the cleanest structure paper in the set. It learns a single generative skill model over both action trajectories and predicate-belief trajectories, then uses the predicted predicate rollout as an online symbolic interface for planning, monitoring, and recomposition. That is much better than stapling a separate classifier onto a policy after the fact. The limitation is obvious but important: the predicate vocabulary and symbolic planning domain are still manually specified.

GaussianDream is competent, but I do not buy the strongest framing. It adds a feed-forward 3D Gaussian reconstruction and short-horizon future Gaussian prediction module during training, then discards the heavy decoding heads at inference while keeping a learned spatiotemporal prefix for action generation. That is a useful way to inject geometric supervision into a VLA. But calling it a “world model” risks overstating how much explicit predictive state is actually used during control.

Most relevant today: ECHO: Continuous Hierarchical Memory for Vision-Language-Action Models.

What makes ECHO worth attention is not the hyperbolic branding, it is the narrower systems claim underneath it. The paper argues that manipulation memory should be organized so that coarse task semantics, subgoals, and local action experience are retrievable at different abstraction levels, with hierarchy-aware filtering before action priors are injected back into the policy. On LIBERO-Long, that setup improves the reproduced π0 baseline from 80.7 percent to 93.5 percent, and the ablation path is actually informative: short-term buffering helps a lot, flat memory helps only a little, hyperbolic organization helps more, and entailment-aware tree retrieval plus consolidation helps most.

This matters for cabbageland because it is a real attempt to replace flat latent mush with typed reusable memory structure that changes retrieval behavior. The paper is still scaffold-heavy and depends on VLM-mediated subgoal extraction and verification, so it is not cleanly learned end to end. But the structural burden is at least legible and testable.

The main framing update is that memory papers should be judged by retrieval contract, not by sentimental talk about long-term context. ECHO earns partial credit because its ablation isolates what the hierarchy is buying over short-term context and flat memory. That is much stronger than papers that call something “hierarchical memory” when they merely add another cache.

PACTS sharpens a second point. If you want compositional skill reuse, a symbolic interface should appear inside the rollout object itself, not as a separately trained monitor glued on afterward. Jointly generating actions and predicate-belief traces is a more defensible design than training a policy and then hoping a detached symbolic layer can explain it.

GaussianDream provides the negative calibration. Strong geometry-aware supervision can improve manipulation, but that is not the same thing as giving the deployed agent a planning-grade explicit state model. The paper looks useful as a training recipe and less convincing as a world-model paper in the stricter sense.

The best paper today is ECHO because it makes a real argument that long-horizon manipulation benefits from hierarchy-aware memory retrieval rather than flat similarity search, and it backs that claim with a meaningful ablation path. PACTS is the more principled compositionality paper, because it builds symbolic outcome traces directly into the skill model and uses them for planning and monitoring, though it still depends on hand-designed predicates and operators. GaussianDream is a solid geometry-supervision paper masquerading a little too hard as a world model. The shared lesson is simple: explicit structure matters when it narrows the interface between experience, control, and reuse in a way that can actually be inspected.
