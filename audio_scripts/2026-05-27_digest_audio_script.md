SMoDP is the most relevant paper today. Its core claim is that mixture-of-experts routing for manipulation should not be driven only by low-level latent statistics or diffusion noise level, because that tends to split semantically similar behaviors across different experts. The paper uses offline VLM-produced verb-noun skill labels, trains a lightweight skill predictor, and routes action chunks according to predicted skill phase. I like the underlying instinct: if expert modularity is supposed to help compositional reuse, then the routing interface should expose reusable behavioral structure instead of hoping the experts discover it accidentally. The main caveat is that the semantic structure is partly scaffolded by a VLM annotation pipeline, so some of the cleanliness comes from extra supervision rather than from a naturally emerging modular policy.

Can VLA Models Learn from Real-World Data Continually without Forgetting? is less architecturally exciting, but more important than it looks. The paper builds a four-task real-world sequential manipulation stream and shows that naive sequential fine-tuning of a π0.5-style policy catastrophically forgets earlier tasks. More interestingly, it argues that modest replay can help a lot, but only if practical details like replay frequency and action normalization are handled carefully. This is exactly the kind of paper that should affect how later continual-learning claims are read. If a method says it resists forgetting, the first question should now be whether it was tested in a heterogeneous real-world stream and whether the training protocol avoided future-information leakage.

Most relevant today: SMoDP.

The useful part is not “mixture of experts” by itself. Plenty of MoE papers just add sparse routing and call the resulting fragmentation modularity. SMoDP at least tries to define what the reusable unit is supposed to be: a semantically meaningful manipulation phase, represented as a skill-like verb-noun chunk. That is closer to the right question for compositional control.

This matters for cabbageland because it sharpens a standard suspicion: pseudo-modularity often appears when the decomposition does not touch the interface where reuse decisions happen. Here the interface is routing. The paper’s answer is not fully satisfying, because VLM-generated skill labels do a lot of the structuring work, but it is still much better than pretending low-level routing statistics alone will recover human-legible behavior phases.

SMoDP is useful mainly as a challenge to lazy MoE framing in robotics. After this paper, it feels weaker to claim compositionality from sparse activation alone if the routing mechanism has no explicit notion of behavioral phase or skill compatibility.

The continual-learning paper has stronger baseline impact than novelty glamour. It says that real-world sequential VLA learning is brittle enough that protocol details, especially replay scheduling and action normalization, can decide whether the whole setup looks viable or hopeless. That should make future forgetting papers easier to interrogate.

The best paper today is SMoDP because it pushes modularity down to the routing decision instead of merely scaling an MoE policy and hoping experts self-organize into reusable skills. The most practically important paper is Can VLA Models Learn from Real-World Data Continually without Forgetting? because it shows that continual VLA learning in the real world is still fragile, and that small implementation decisions can dominate the conclusion. The shared lesson is that explicit structure matters most when it changes the actual computational bottleneck, either which expert gets activated or whether previously learned skills survive sequential updates at all.
